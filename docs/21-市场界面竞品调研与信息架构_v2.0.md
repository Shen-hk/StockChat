## 1. 竞品市场页真实模块清单（一手来源）

### 1.1 富途牛牛（官方手册，模块数最多的样本）

来源：`futuhk.com/hans/manual/topic11_165`（App v13.47 官方帮助）

港股市场页自上而下 **14 个模块**：市场指数 → 亮点工具 → 高股息率榜 → 业绩日历 → 财经日历 → 概念板块 → 特色榜单 → 智能盯盘 → 全部股票 → 走势预测 → 产业链 → 热力图 → 衍生品数据统计 → 涨跌数据统计。
美股页多出「机构跟踪」「评级变动榜单」，少「衍生品统计」。
Overview 页横向覆盖：股指 / 期货指数 / 商品 / 外汇 / 债券。

**三条可借鉴的结构性事实**
1. **模块可自定义增减与排序**（「更多」→设置→编辑）。承认「一套固定布局服务不了所有人」。
2. 每个模块都是「摘要 + `>` 进详情」的两级结构，摘要只放 2 行左右，详情才是筛选器 + 全表。
3. 日历类（业绩/财经/派息）是独立第一级模块，不是塞进资讯里。

### 1.2 雪球（三级页签，A 股结构最接近我们）

来源：`xueqiu.com/5667109964/149324785`

搜索框 → 横向市场页签（全球 / A股 / 港股 / 美股 / …）
- **全球**：沪深指数 → 股指期货 → 汇率指数 → 全球商品 → 其他指数（恒生、日经、富时A50、道指纳指标普、英德法）→ A50 期指
- **A股** 下再分三个子页签：
  - 沪深：三大指数 → **市场概况（全部股票涨跌比例 + 跌停涨停比）** → 股票排行（涨幅榜/跌幅榜…）
  - 板块：涨幅前三 + 跌幅前三 → 板块涨跌列表
  - 科创板

**可借鉴**：「涨跌比例 + 涨跌停比」被单独命名为**市场概况**并置于指数之下、榜单之上——和我们 v1.0 的「市场宽度条」判断一致，说明位置选对了。

### 1.3 IBKR Mobile（Markets 页，双 tab 结构）

来源：`interactivebrokers.eu/campus/trading-lessons/iphone-research-markets-page/`

顶部 **Markets | News** 双 tab。Markets 侧模块可自定义增删排序：Market Indices / Events / Market Trends / Performance by Sector / Discover / Currencies / Popular Lists。
- Events = earnings + economic events + dividends + IPOs，可按区域筛
- Market Trends = Top Movers / Most Active / Top Options Volume（同一区块三个切页）
- Performance by Sector = 12 个行业 ETF 的**热力图**
- News 侧 = Daily Overview / Portfolio News / Watchlist News

**直接对应我们的需求**：用户要的首页「AI / 市场」双模，IBKR 已用 `Markets | News` 验证过——**顶部双 tab 是成熟范式，不是我们自创的怪结构**。且 News 分「大盘/持仓/自选」三层，正是我们「自选联动」的现成模型。

### 1.4 同花顺 vs 东方财富（定位差异 → 数字大小差异）

来源：`mguba.eastmoney.com/mguba/article/0/1141200674`

- 底部五栏顺序即定位声明：同花顺 = 首页/**行情**/自选/交易/资讯；东财 = 首页/**资讯**/自选/行情/交易
- 同花顺侧重价格与资金（亮点/盘口/资金/诊股占主页面 3/4），**数字显示明显更大**，信息量相对有限但清晰
- 东财侧重公开信息（股吧/资讯/公告/研报/财务/资料），**同一屏信息量更大、数字更小**

**这条是「Demo 太小」的正解**：数字尺寸不是审美偏好，是定位选择。我们服务新手解释场景 → 走同花顺路线（**数字大、单屏模块少、层级深**），而不是东财路线（密、小、平）。v1.0 的错在两头都不靠：数字不够大，信息也不够多。

## 2. A 股复盘信息全集（本土特有，海外产品没有）

依据 2026-09-02 多份公开复盘的字段交集，A 股散户实际看的指标可归为 8 组。**加粗项为海外行情 App 普遍不具备、必须本土化的部分。**

| 组 | 字段 |
|---|---|
| 指数 | 上证/深成/创业板/科创50/**北证50**/沪深300/上证50/中证500：点位、涨跌幅、成交额 |
| 量能 | 两市总成交、**较昨日增减额**、**较近5日均值偏离%**、缩量/放量定性 |
| 涨跌结构 | 上涨/下跌/平盘家数、**红盘率**、涨幅>5% 数、跌幅>5% 数 |
| 情绪（A股核心） | **涨停家数（含/不含ST口径）**、**跌停家数**、**炸板数与炸板率**、**封板率**、**连板家数**、**最高连板高度**、**1进2晋级率** |
| 连板梯队 | **4板/3板/2板/首板 的股票名单与分布**、**一字板 vs 换手板**、封单额与封单占比 |
| 资金 | **北向资金净流入（沪股通/深股通分拆）**、占成交比、**两融余额**、行业主力净流入/流出 Top、**龙虎榜机构 vs 游资** |
| 板块 | 行业涨跌幅榜、概念涨跌幅榜、板块成交额、**板块涨停家数**、**主线切换判定** |
| 日历/事件 | 财报预约披露、经济数据、新股申购、解禁、分红除权 |

### 2.1 口径冲突必须显式标注（沿用项目铁律）

同一日期的北向资金在不同来源出现 **−66.14 亿**（沪股通 −60.07 / 深股通 −6.07，成交 1023.49 亿占比 10.56%）与 **−402 亿** 两个数；涨停数出现 **53 / 54 / 60** 三个数（是否含 ST、新股、北交所，以及 15:35 收盘口径 vs 全时段池口径）。
**设计要求**：所有情绪类数字必须有 `口径` 角标，长按/点击展示口径定义。这不是加负担，这是我们「解释器」定位的天然优势——竞品直接给数字，我们给数字 + 口径。

## 3. 我们装什么、砍什么（RICE 取舍）

原则：**克制不是少给信息，是少给层级**。第一屏只放「定性 + 三个数」，深度信息全部下沉到第二级。

### 3.1 收（进第一级，共 9 个区块）

| # | 区块 | 为什么必须有 | 数据源 |
|---|---|---|---|
| A | 时段状态条 | 盘前/竞价/盘中/午休/盘后 语义完全不同（§5） | 本地时钟 |
| B | 情绪定性 Hero | 用户要的是「今天什么行情」，不是 8 个数字 | 计算 |
| C | 指数带（可横滑 8 个） | 北证50 逆势 +2.50% 这种信号只在完整指数带里可见 | 腾讯快照 |
| D | 量能条 | 「1.79万亿，缩量 2422亿」是 9-2 最重要的一句话，v1.0 完全没有 | 腾讯快照聚合 |
| E | 市场宽度 | 1541 涨 : 3901 跌，红盘率 27.7% | 新浪全市场列表 |
| F | 情绪四维（涨停/跌停/封板率/最高板） | A 股特有，海外无，是我们的本土护城河 | 东财涨停池 |
| G | 连板梯队 | 4板2只→3板4只→2板7只 的**坍塌形状**比任何单数字都直观 | 东财 lbc 字段 |
| H | 板块分层榜 | 领涨/领跌 + 板块涨停数 + 主线切换 | 东财板块排行 |
| I | 资金三行 | 北向 / 行业主力进出 Top / 龙虎榜机构游资 | 东财资金流 |

### 3.2 放（第二级，`>` 进入，不占首屏）

热力图全景、全部股票筛选器、涨跌幅/换手/量比多维榜单、财报与财经日历、龙虎榜全表、两融、全球市场（港美股 + 商品 + 汇率）、行业主力资金全表。

### 3.3 砍（明确不做，写进 Non-goals）

选股器 / 智能盯盘条件设置 / 走势预测 / 产业链图谱 / 衍生品统计 / 评级变动榜 / 高股息榜 / 股吧社区。
理由：前 4 项是「工具」不是「解释」，与产品定位冲突；评级与高股息属中证协 2026-06 分级中的**高风险（个股推荐、估值）**格。

## 4. 「AI 味太重」的诊断与三条铁律

### 4.1 诊断

v1.0 在 7 个区块里挂了 7 个「问 AI」按钮 → AI 从能力退化成**贴纸**。用户感知到的不是智能，是「这页每处都在推销 AI」。竞品对照：富途 14 个模块里 AI 元素 0 个常驻，新浪财经的 AI 摘要也只在财报页内联出现。

### 4.2 三条铁律

**铁律 1 · 条件触发，不常驻。** AI 解释只在数据越过阈值时出现，行情平静时整页 0 处 AI 元素。
阈值示例：量能偏离 5 日均值 >10%｜封板率 <80%｜最高板较昨日下降 ≥2 板｜某板块涨停数环比骤降 >70%（主线终结硬信号）｜北向单日净流出 >50 亿。

**铁律 2 · 一行归因，贴在数字旁。** 形态是紧跟数字下方的**一行内联注释**（≤28 字），不是独立卡片、不是段落总结。
- ✅ `1.79万亿 · 缩量2422亿` → 下方一行：`退潮缩量：冲高回落后资金离场，与8月底地量性质不同`
- ❌ 独立的「🤖 AI 智能解读」渐变卡 + 三段话

**铁律 3 · 全页 AI 预算上限。** 常驻 ≤1 处（Hero 定性一句话），条件触发 ≤3 处，页面底部 1 个「让 AI 讲讲今天」收口。**总计不超过 5 处，且 4 处是文字不是按钮。**

### 4.3 视觉黑名单（出现任意一项即判定「AI 味」）

紫色/靛蓝渐变底 · ✨🤖 类 emoji · 「AI 智能解读」标签 · 机器人头像 · 常驻打字机光标 · 超大圆角对话气泡 · 「为您推荐」「猜你想问」话术 · 每模块一个「问 AI」按钮 · 呼吸发光边框。

**替代做法**：AI 内容用**正文同色 + 左侧 2px 品牌蓝竖线**呈现，靠排版而非配色区分。它读起来应该像编辑写的注解，不像机器人插话。

## 5. 时段态：v1.0 完全缺失的一层（含官方交易规则依据）

行情界面在不同时段的**语义不同**，同一套 UI 直接复用是错的。灰色在 A 股软件里是官方语义：非交易时段、停牌、平盘三种情况都用灰。

| 时段 | 界面语义 | 关键差异 |
|---|---|---|
| < 9:15 盘前 | 昨收盘数据 + 今日日历 | 全部数字**灰色**；隐藏情绪四维；主位给「昨日复盘 + 今日待办事件」 |
| 9:15–9:20 | 竞价（可挂可撤） | 显示匹配价/竞价涨幅/未匹配量，**但必须标注「此段虚假大单多，参考价值低」** |
| 9:20–9:25 | 竞价（只挂不撤） | 撮合价参考价值高，可正常呈现；竞昨量比是核心指标 |
| 9:25–9:30 | **静默期** | 交易所不刷新竞价，盘口消失是正常现象 → **必须显式提示「静默期，非故障」** |
| 9:30–11:30 / 13:00–15:00 | 连续竞价 | 全量实时，tick 闪烁与脉冲预警生效 |
| 11:30–13:00 午休 | 数据静止 | 全局**灰色降饱和**，标题「午间休市 · 数据静止」，动效全停 |
| 14:57–15:00 | 收盘竞价 | 盘口切竞价模式 |
| > 15:00 收盘 / 休市 | 复盘态 | **主位从「现在怎样」切成「今天怎么了」**：连板梯队、主线切换、龙虎榜升到前面 |

**这是竞品普遍偷懒、而我们「解释器」定位天然该做的地方**：静默期提示、竞价前 5 分钟的虚假大单警告，本质都是解释，不是行情。

## 6. 信息架构总图

```
市场页
├─ 顶部：时段状态条（常驻，决定下方全部模块的呈现态）
├─ 第一级（单页纵向滚动，9 区块，约 2 屏半）
│   A 时段条  B 情绪Hero  C 指数带(横滑8)  D 量能条
│   E 市场宽度  F 情绪四维  G 连板梯队  H 板块分层榜  I 资金三行
│   └─ 每区块右上 `>` 进第二级；AI 注释按 §4 铁律条件出现
├─ 第二级（独立页，来自区块下钻）
│   热力图全景 / 全部股票 / 多维榜单 / 日历 / 龙虎榜 / 两融 / 全球市场
└─ 复用出口：MarketSnapshot(A+B+C+D+E) → 首页「市场」模式
```

**MarketSnapshot 定稿为 A+B+C+D+E 五块**（时段+定性+指数+量能+宽度）。理由：这五块回答「今天大盘怎么了」且**不含任何个股名称**——首页是 AI 会话入口，出现个股名会诱导点击进而滑向「推荐」语义，触碰合规红线。连板梯队与板块榜含个股/板块名，留在市场页内。

【二、项目铁律（违反即任务失败）】
R1 响应式读取：observable 只能在 attr{} / event{} / vif{} / vfor{} / vbind{} 闭包内读取；普通 body() 或子 builder 闭包读到的是挂载快照。
R2 动画绑定：attr{} 内先读其它 observable，再设 transform/opacity，最后读动画 driver 并让 animate() 成为该 attr 最后一条状态相关语句。theme 等值必须在 attr 外缓存，不得在 attr 内读。

R6/R7：见仓库根目录 AGENTS.md 的 R6、R7 两节（含 attr 条件属性必须无条件全量赋值、vif creator 只构建一次、Scroller 触摸顺序等）。

## 3. 提示词 P2 —— 关键模块组件 DSL 化

### 3.0 「DSL 化」的口径（派单前请确认；如理解不同请改写本节）

本项目所说 **DSL 化**，指把「命令式散点参数 + 多处分支复制 + 隐式时序约定」的组件，改造为**类型安全的声明式 Kotlin DSL builder**。合格标准是同时满足：

1. **单一入口函数**：调用点只写一个 builder（如 `quoteIsland { … }`、`aiStream { … }`、`segmentedControl { … }`），内部用 receiver scope 收集配置。
2. **显式契约**：Props / Actions / Slots 全部具名且类型化；非法组合在编译期被拒绝（例如「phase=IDLE 却传了 dragOffset」应无法构造）。不得把 BasePager、整个 ViewModel、Repository 或 `Any` 传进组件。
3. **时序内聚**：状态机、Timer、版本守卫、两帧入场只在 DSL 内部或唯一 Coordinator 里，调用方只能声明「意图」（Intent），不能自己 `setTimeout`。
4. **变体单源**：新增一个变体（新市场、新周期、新卡片类型、新面板项）只改一处注册表 / 一张声明表，不新增分支复制。
5. **与 R1–R7 兼容**：DSL 生成的视图仍满足「observable 只在 attr/event/vif/vfor/vbind 内读」「animate() 是该 attr 最后一条状态相关语句」。
6. **零行为变更**：视觉、文案、动画时长、延迟毫秒、手势阈值逐帧一致。

DSL 化的目的不是「写起来好看」，而是：新增一个变体的改动点从 N 处降到 1 处、时序不变量由类型与单例保证而不是靠注释。

   - 游标层：十字线、跟随点、气泡 —— 只读高频驱动，独立 Canvas。
   - 旗标/动画层：flagDropProgress、selecting 相关，独立于前三层。
   分层后必须保证原有层叠顺序、透明度、混合与裁剪效果逐像素一致（有叠加/半透明处要说明如何保持）。
2. **高频驱动治理**：scrubMinute / motionPhase 等不得进入 vbind key；呼吸动画按需降频或降精度（给出可配置常量与理由），不得出现肉眼可见的节奏变化。
3. **几何缓存策略**：明确缓存 key（quote 版本 + 尺寸 + band + 状态），并在尺寸/数据变化时精确失效；禁止「缓存永不失效」导致的数据错位。
4. **列表/滚动场景**：确认详情页在 Scroller 内滚动时图表的重绘/布局行为，若存在滚动期重绘，给出修复。
5. **K 线图与卡片内小图**：同一套分层策略复用；若 API 不同，抽出共享的绘制基元到 shared/chart（纯计算 + 绘图原语）。

三、必做的量化流程（不接受「感觉变快了」）
1. **先做基线测量**，用项目已有的打点手段（可新增仅 Debug 生效的计数器，禁止进 Release 路径）统计并记录到 outputs/p3-baseline/：
   - 图表区域每秒重绘次数 / 单次重绘耗时（或绘制调用数）；
   - draw 闭包内的 observable 读取次数与 attr 重跑次数；
   - scrub 时序：从手指移动到画面更新的延迟（配合 16ms 帧合并现状）；
   - 详情页首帧到图表可交互的时间、以及进页面时的请求-渲染总耗时中图表所占比例。
2. **优化后测同一组指标**，给出 before/after 表格。任一项恶化需解释。
3. 在三端各跑一次：Android 真机、iOS 模拟器、H5 浏览器，滚动 + scrub + 切换周期三种场景。

四、边界与禁止
- 不改：图表配色、线宽、圆角、网格密度、价格区间算法、量能柱宽度、声呐/旗标视觉、随值卡内容与位置。
- 不改交互阈值：圈选即问仍是「横拖 > 14dp 且 |dx| > |dy| × 1.5」；长按拍 Scroller scrollEnable(false) 的机制不变；settle 仍是两拍（R5）。

1

氛围色由涨跌驱动

整页顶部 wash 取 riseSoft / fallSoft，60% 处渐隐回 page 底色；走势卡后置同色 radial 光晕。价格、涨跌 pill、蒙层值、量能条全部走同一语义色；平盘/停牌整体降饱和取 flat 灰。只复用 doc 19 权威 token，不新增饱和色。

2

自绘分时 = 页面第一实体

高度 132px → 约 340px（3.2 倍篇幅），信息密度同步升级：价格线（语义色 + draw-on）+ 均价线（虚线）+ 昨收虚线基准 + 上下对称涨跌幅轴 + 分钟量能 + 最高/最低锚点 + 十字光标随值卡。数据源不变（腾讯分时，实测可用），优化的是绘法与篇幅，不是换资源。

3

行情数据 → 图表蒙层

今开 / 最高 / 最低 / 换手率四个「读走势时最想要」的值，收成一条玻璃 chip 条（marketGlass + blur14）压在走势底部——按涨跌相对昨收着色。从「与走势并列的 8 格卡」变成「走势的注脚」，主次即层级。

4

其余指标 → 次级行

成交量 / 成交额 / 总市值与昨收 / PE / PB / 振幅收为卡下两行小字（muted 面、9.5px 标签），不再与走势争位。AI 只保留一行事实性归因（盘中涨跌驱动的一句陈述），无「问 AI」按钮铺陈，符合 AI 克制三铁律。

5

新闻弹幕带（单条队列式）

位置：Hero 与走势主卡之间，不叠在走势上——保住「走势=唯一主实体」的遮蔽测试（LDRS-L），也不与十字光标手势冲突。形态定为单车道队列：一条完整飘出 → 1.5s 间隔 → 下一条（≈55px/s，长标题自动放慢）。理由：详情页是「读」的场景，双车道是持续背景噪音；个股新闻低频，高吞吐播低价值内容；克制=护城河。双车道灯带留给市场页快讯 ticker。悬停暂停，点击出玻璃摘要卡；内容仅标题+来源+时间，不做涨跌染色；无新闻整条隐藏。

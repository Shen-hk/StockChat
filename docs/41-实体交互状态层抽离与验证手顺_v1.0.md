## 1. 切片定义

**迁入**（`chat/entity/state/EntityInteractionCoordinator`）：静止长按预览、长按转拖拽、投放目标判定、二义实体选择、拖拽收敛。

这四件事**共享同一状态机**（`start → 超阈值转拖拽 → end 投放`），因此按 doc 39 定义一体迁移；硬拆会把共享字段劈成两个 owner。

**仍留页面**：

| 留在页面的东西 | 理由 |
|---|---|
| `renderEntityDragOverlay` | 纯渲染（DSL），读 state getter 即可 |
| `isIslandFirstCompareDrop` | 纯查询，且**同时读岛状态 observable**（`islandCompareLeftSymbol` / `islandTermCompareLeftKey`），DSL 在 attr 内调用，必须保持页面侧反应式读取 |
| `insertDraggedMention` | Composer 域（@ 提及），由 Effect 驱动 |
| `addWatchlistFromEntity` | 自选域（`WatchlistStore`） |
| `handleTextSelectionLongPress` 及消息选择/长按菜单域 | 属「消息长按操作菜单」，不在本切片 |
| `handleStockEntityClick` 等入口 | 一行委托；`entityDisplayName` 供 HostPort 实现复用 |

## 7. 失败时排查路径

| 症状 | 先查 |
|---|---|
| 浮层不出现 / 不跟手 | `vif({ page.entityDragActive })` 是否读到 state（页面 getter 转发）；拖拽阈值是否达标（>10dp） |
| 松手无动作 | Effect 是否落到 `handleEntityEffect`；`EntityDropResolver.resolve` 的落点是否落进捕获区（对照 §3 几何） |
| 投放目标不切换 | HostPort 的 `keyboardHeight()` / `isIslandExpanded()` 是否返回新值（两者都影响捕获区边界） |
| 岛未切对比态 | 属第一刀契约：`QuoteIslandCoordinator.isCompareLobbyVisible()` 必须读 `state`（勿读镜像） |
| 长按后误触提问 | `consumeTermClickSuppression` 是否被调用；抑制窗口 400ms |
| 预览气泡不消失 | `dismissPeek` 的 180ms 兜底与 `peekVersion` 守卫 |

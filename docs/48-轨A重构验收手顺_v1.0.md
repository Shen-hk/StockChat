## 0. 先理解这次重构「不测什么」

本次三个工作包全部是**物理归档 + 职责搬家**：

- 不改产品功能、视觉、文案、动画参数、手势阈值、路由、AI Prompt、降级策略、平台协议；
- 不改任何行情字段解析、`slotCount`、`lotSize` 规则；
- 未触碰 `PlatformPolicy`（四端平台隔离开关）。

所以验证的重点**不是**「功能对不对」，而是：

1. **有没有搬漏 / 搬错**（符号是否仍能解析、页面是否仍能渲染）；
2. **有没有在搬家过程中夹带行为改动**。

第 1 项靠编译 + 单测 + 眼验；第 2 项靠第 2 节的等价性证明。

## 2. 第 0 层验证：证明「没有夹带行为改动」（不需要跑 app）

这一层是本手顺最有说服力的部分 —— 它把「重构」还原成「位置变更」。

### 2.1 证明 1：切割前后内容逐字一致

```bash
cd <repo>
git show c211d59:shared/src/commonMain/kotlin/com/kuikly/stockchat/page/StockDetailPage.kt \
  | awk 'NR>=1305' > /tmp/old-blocks.kt
grep -vE '^(package|import) ' \
  shared/src/commonMain/kotlin/com/kuikly/stockchat/detail/page/component/DetailPageBlocks.kt \
  > /tmp/new-blocks.kt
diff /tmp/old-blocks.kt /tmp/new-blocks.kt
```

**预期差异只有 3 处**（2026-09-12 实测）：

```text
0a1,4                                    ← 新文件头部多出原文件的 4 行（空行 + 一行 import 分组注释）
412c416
- private fun ViewContainer<*, *>.SecondaryMetricRow(
+ internal fun ViewContainer<*, *>.SecondaryMetricRow(
815c819
- private fun ViewContainer<*, *>.DetailBottomBar(
+ internal fun ViewContainer<*, *>.DetailBottomBar(
```

除这 3 处外**没有任何差异** = 搬走的 1900 行代码一个字都没变。

### 2.2 证明 2：SourceStampLine 合并前后渲染逻辑逐字一致

```bash
cd <repo>
git show c211d59:shared/src/commonMain/kotlin/com/kuikly/stockchat/cards/components/SourceStampLine.kt \
  | grep -A 20 'fun ViewContainer' | sed 's/CardSourceStampLine/SourceStampLine/' | tr -d ' \n\t' > /tmp/a.txt
grep -A 20 'fun ViewContainer' \
  shared/src/commonMain/kotlin/com/kuikly/stockchat/foundation/ui/feedback/SourceStampLine.kt \
  | tr -d ' \n\t' > /tmp/b.txt
diff /tmp/a.txt /tmp/b.txt
```

**预期差异只有 2 处**：`internalfun…` vs `fun…`（可见性），以及一个可省的分号（`paddingBottom(3f);borderRadius(7f)` vs `paddingBottom(3f)borderRadius(7f)`）。
字号、间距、配色、文案、OFFLINE 分支判断全部一致。

### 2.3 证明 3：全部 Kotlin 改动里，除上述之外只剩 import

```bash
cd <repo>
git diff c211d59..HEAD --numstat -- 'shared/**/*.kt' \
  | awk '{n=$1+$2; if (n>=5) printf "%5d  %s\n", n, $3}' | sort -rn
```

除 `StockDetailPage.kt`（1932）与 `DetailPageBlocks.kt`（1898）这一次切割的两端外，
其余每个文件的改动都 < 35 行，且逐行看只有 `import` / `package` 行（见 1.1 档 A）。

## 0. 根因诊断：堆叠感从哪来

v1（RiskMapPage）已过 LDRS 重构（8/12），面板不丑、口径诚实，但**结构上仍是六个竖条**：

| # | 根因 | 实证 |
|---|---|---|
| 1 | **一张网被切成六条竖条** | 股票×行业×相关×事件本是一张关系网，六个面板各自为政、形态各异却互不相连，用户读完要自己拼回网 |
| 2 | **同一个名字重复出现 6 次** | 「中际旭创」在行业 chip、集中度条、相关矩阵、波动、事件、情绪里反复出现——重复感即堆叠感 |
| 3 | **信息只能读，不能探** | 结论全部预铺，用户是读者不是探索者；相关性明明可以体感，却只是矩阵里一个色块 |
| 4 | **AI 插在滚动流里** | 3 处静态注释位置固定、与行为无关——AI 参与了排版，没参与探索 |

**结论：不删信息、不换数据链，换信息的组织方式。**

## 1. 定案总纲：一张图，多图层

六个维度收成同一张**持仓星图**的五种投影。每只自选是一颗星，一颗星承载全部维度，名字只出现一次：

| v1 面板 | 星图语言 | 投影层（口语命名） | 映射规则 |
|---|---|---|---|
| 行业重叠 + 集中度 | 位置 + 团域 | **抱团**（默认） | 同链聚成一团；团域大小=集中度（CR3 口径） |
| 相关性（热力矩阵） | 连线 | **牵连** | \|r\|≥0.5 才连线；粗细/亮度=强度；孤星自动浮现 |
| 波动暴露（双条） | 光晕 | **颠簸** | 光晕按波动倍率呼吸；标「N×大盘」（等权） |
| 事件时间轴 | 徽标 + 时间刷 | **日程** | 星旁「财/解/息」徽标；拖刷扫未来 30 天，扫到哪天那颗星亮 |
| 情绪暴露（列表） | 环纹 | **热度** | 连板星加弧线环纹（一圈=一连板），其余星退暗 |

关键性质：**切层时星星不换位置、不刷页面，只变形高亮**——五个维度在同一套空间记忆里展开。列表形态（v1）保留为第三档降级投影，不是被删除。

## 2. 交互创新（三则手势，全单手拇指可达）

| 手势 | 做什么 | 为什么强 |
|---|---|---|
| **拖星牵引**（牵连层） | 长按星拖动，相关星按 r 比例被牵引跟随（r=0.86 几乎贴着走，r=0.42 只是微动），松手弹簧回弹 | 相关系数从色块变成**手感**；doc 07「手势即提问」基因的落法 |
| **长按星 → Context Bar** | 按住 0.5s 弹出提问 chips（按当前图层生成：抱团层问"谁和谁一团"，日程层问"解禁那天会发生什么"） | 复用首页长按基因；不跳页 |
| **时间刷**（日程层） | 拖动手柄扫未来 30 天，事件日星星亮起 + 一句事实（解禁≠减持，但可流通筹码增加） | 事件从"列表"变成"**预演**"；回答"接下来哪天最颠" |

另有点击选中：点星 → 顶部焦点注释 + 底部成员抽屉（两次点击到详情：星 → 抽屉 → 详情）。

## 3. AI 交互创新：从"流里的文字"到"地图上的位置"

| 形态 | 说明 | 预算 |
|---|---|---|
| 旧：静态注释（v1） | 3 处固定插在滚动流，与行为无关 | ≤3，平静 0 |
| **新① 引路星（Beacon）** | 规则引擎判定"最挤/最颠/最热"的一团 → 星图该团外圈**脉冲光环**（AI 的产出=地图上的一个位置），旁注 ≤28 字；点击光环升起**解读抽屉**：3 行规则事实 + 追问出口（openChatWithQuestion → 复用 AttributionIntent 卡片） | 条件触发 ≤2 |
| **新② 焦点跟随（Spotlight）** | 选中星/团/日期时，一句跟到选中对象旁的**事实观察**浮现（"新易盛：与 3 只相关系数>0.6，同链共振里最颠的一颗"）；取消选中即收起。**AI 跟随手电筒，不铺满页面** | 条件触发 1 |

预算账本：L1 头部句为规则生成（非 AI、0 预算）+ 引路星 ≤2 + 焦点跟随 1 = **≤3、平静时 0**，与 FR-R4 持平。全部句子端侧模板生成、数字来自 Provider（ADR-11 零幻觉），不走 LLM——符合 doc 23「暴露指标不调 LLM」。

### 3.1 追问出口：跳转对话页，不做页内内嵌对话（2026-09-08 定案）

问题：Context Bar / 引路星解读抽屉的追问出口，是在风险地图页内就地展开对话，还是点击后跳转 ChatPage？

**定案：统一跳转 `openChatWithQuestion`，并注入焦点上下文；不做页内内嵌对话。**

| 考量 | 跳转对话页 ✓ | 页内内嵌对话 ✗ |
|---|---|---|
| 会话架构 | 复用 ChatPage 唯一会话容器（卡片/流式/历史），doc 29 详情页已验证同模式 | 出现第二个对话容器，就地问答不进主会话历史，或需会话同步 |
| 三模块闭环 | 追问 → 对话 → 术语收口 GlossaryStore.encounter → 知识库，链路完整 | 收口与会话历史断在风险地图页内 |
| 成本 | 通路现成 | 需处理输入法、星图手势与消息滚动冲突、消息卡片渲染复用，预估膨胀 |
| 交互摩擦 | 追问本身低频（三铁律限触点），跳转可接受；返回栈可回 | 心流不断，但代价是架构债 |

配套两个 P0 增强（让跳转"无感"）：

- **上下文注入**：`openChatWithQuestion(question, { source:'RISK_MAP', focus:{ type:'star'|'cluster'|'day', id, layer } })`。问题保持自然语态（不带"来自风险地图"等前缀），上下文走参数；AI 首答直接落归因卡（AttributionIntent 通路），卡头带焦点徽标（如「风险地图 · 牵连层 · 新易盛」）。
- **返回态保持**：从对话页返回风险地图时，恢复图层、选中焦点、时间刷位置——地图状态不因跳转重置，用户从"问完"回到"刚才看到的地方"。

## 4. 与既有铁律/契约的一致性

- **合规（doc 23 §4.1）**：无等级/匹配/评分词；层名"抱团/牵连/颠簸/日程/热度"全为事实语态；全图中性明度阶梯 + brand 蓝仅交互态（星图不引涨跌情绪色，星点涨跌幅文字沿用既有红绿 token）；"不做总分（N-R5）"升级满足——星图无综合分，五投影各自成立。
- **联动契约**：C-1（自选唯一输入）不动；C-2（术语收口 GlossaryStore.encounter）改为每层 tip 一词可点；C-3（AI 预算分账）按 §3 账本执行；C-4（口径诚实）角标常驻 + 每层小字自带口径。
- **LDRS 自评：11/12**（v1 为 8）：L3 / D3（z0 氛围底 / z3 星图主卡玻璃唯一 / z2 chips+抽屉 / z4 Context Bar）/ R3（关系→图形 8 类映射命中 5 类）/ S2。
- **六维度计算原样复用**：industryStats / chainConcentration / pearson / portfolioStd / stdOf 等纯函数不动，只换渲染层；数据链三级降级不动。

## 0. Design Read（方向断言，已拍板）

```
Lazy default（已否决）：玻璃态 Hero 卡 + generic 蓝品牌 + 8 个相同 bento 块（最早的版本）
Design Read：A股 行情详情 · 安静交易终端 · register=h5+product · SPECTACLE=3
            layout=Hero 大数字 + 走势图中心件 · 6 种版式交替
You'll see：浅色 off-white 手机页面（不是纯白）；顶部股票名与一个大号等宽价格；
            往下是发丝边框的数据卡、一张可触摸十字光标的分时图、一条资金流发散条、
            财务 tiles、公告列表，最后一块带深蓝左边线的 AI 解读面板。
            深蓝只出现在「AI 与你的操作」上，红/绿只表示涨/跌。
Motion：首屏  价格与数字从 0 滚动到真实值
        滚动  每块卡片淡入上移，分时图描边画出
        图表  手指划过出现十字光标 + 价格气泡
        操作  加自选按钮缩放反馈 + toast；AI 解读打字机
        静止版 全部直接显示终态（prefers-reduced-motion 兜底）
Images：无。行情页不需要摄影图，数据即内容。
Decision：用户拍板 ① 品牌色用蓝色（但定制深蓝 #1E5BD6，非 generic #3B82F6）② 浅色版定型
Rotation：明确避开上一版（玻璃+蓝+bento）与「暗绿终端」俗套；用 bespoke 深蓝承载品牌，
          红/绿严格留 A股 语义，绿压深到 #0C7A45 过 WCAG AA。
```

## 1. 配色（浅色 + 深蓝，按 A股 语义改造）

| 角色 | 值 | 用途 |
|---|---|---|
| `--page` | `#F5F6F8` | 浅灰白底，非纯白 |
| `--bg` | `#FFFFFF` | 卡片（白，靠发丝边框区分） |
| `--panel-2` | `#EEF1F5` | 次级面板 / 副图底 |
| `--border` | `rgba(15,23,42,.08)` | 发丝边框，非硬灰线 |
| `--ink-3` | `#69748F` | 标签（对比度 4.67:1 ≥ 4.5） |
| `--accent` 深蓝 | `#1E5BD6` | **唯一品牌色**：AI 解读边线、问 AI 按钮、加自选、当前价脉冲 |
| `--up` 红 | `#D92E2E` | A股 涨（语义，4.79:1） |
| `--down` 绿 | `#0C7A45` | A股 跌（语义，5.2:1，压深过 AA） |

**关键决策**：品牌色绝不选红/绿（会与涨跌幅语义撞车），用定制**深蓝**承载「App/AI/你的操作」，红绿严格留给市场数据——三者各司其职，一眼能分清「这是 App 在说话」还是「市场在动」。深蓝特意避开 Tailwind 默认 `#3B82F6`（finesse 列为廉价信号），取更沉稳的 `#1E5BD6`。

## 2. 相对最早版本的具体纠偏

| 最早版本（被否） | 本版 |
|---|---|
| 玻璃态 Hero 卡（blur 大模糊） | 浅色底 + 发丝边框 + 极淡投影（finesse 把默认玻璃列进 cheapness blacklist） |
| generic 蓝 `#3B82F6` 品牌 | **定制深蓝 `#1E5BD6`**（避开 Tailwind 默认蓝），红绿纯语义 |
| 8 个相同 bento 卡 | 6 种版式：Hero 大数字 / KPI 网格 / 走势图（唯一非卡中心件）/ 资金流发散条 / 列表表格 / AI 面板 |
| 渐变大标题 | 固定字号阶梯（12–44），数字全 `tabular-nums` 等宽对齐 |
| 动效炫技 | 只做「反馈」型动效，SPECTACLE=3，全部 reduced-motion 兜底 |

## 3. 版式家族（≥4，满足 finesse §5）

1. **Hero** — 名称 + 44px 等宽大价 + 涨跌 chip + 日内 spark
2. **KPI 网格** — 行情数据 4 列（总市值跨行带 mini spark）
3. **走势图** — 满宽卡片 + 滑动指示 Tab + 十字光标（唯一非卡中心件）
4. **资金流发散条** — 中轴零线，红右/绿左
5. **财务 tiles / 股东户数** — 2×2 块 + 侧边 spark
6. **列表表格** — 龙虎榜 / 公告研报（数字右对齐）
7. **AI 解读面板** — 深蓝左边线（品牌时刻）

## 4. 预检结果（product-ui §9/§10 + anti-cheap）

- [x] 非纯 `#fff/#000`；发丝边框 + 极淡投影；单一品牌色（定制深蓝，非 generic 蓝）
- [x] 调色板 §7 碰撞检查：accent 不撞 up/down；ink-3 对比度 4.67:1 ≥ 4.5；up 4.79:1；down 5.2:1
- [x] 无 glassmorphism 卡 / 无 gradient-text / 无 per-section eyebrow / 无 em-dash 装饰
- [x] 图表：分时图带昨收虚线基准 + tooltip + 成交量副图；发散条中轴为零
- [x] 交互态：加载（数字滚动）、空态（暂无）、反馈（toast/加自选）、禁用态未涉及
- [x] 底部 3 段栏 + 顶栏滚动紧凑态；触控目标 ≥44px
- [x] `prefers-reduced-motion` 兜底（CSS 回退 + JS 直接置终态）

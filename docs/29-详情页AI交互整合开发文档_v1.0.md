**贯穿叙事**（也是演示脚本）：页面先指给你看（E1 置顶、④ 声呐、B2 旗、A1 回访）→ 用户指给 AI 问（① 圈选、③ 抓取、⑤ 预填、② 联动）。**13 个交互里 12 个纯端侧，仅①的追问环节触发 LLM**——整体惊艳点靠交互与排版重组，不靠模型。

## 2. 整体协调：五条统一规则（本整合的核心）

针对「散装感」风险，所有交互共用以下约束，违反任何一条即回退：

| # | 规则 | 具体落地 |
|---|---|---|
| U1 | **浮层仲裁** | 全页同时最多一个就地浮层（声呐气泡/圈选气泡/新闻摘要/先览气泡/回访卡/理由 chips 互斥）。`OverlayArbiter.show(layer)` 统一入口，开新的先关旧的；点空白全关。 |
| U2 | **一种强调色** | brand 蓝只用于「AI 可交互」元素（气泡、声呐、注脚、chip、旗杆除外）；涨红跌绿只用于数据本身。两者永不混用——用户扫一眼就知道"什么能动"。 |
| U3 | **统一来源标注** | 所有非 LLM 输出一律挂「· 端侧规则」角标；注脚/徽章/旗标点击可见**判定依据**（规则名 + 输入）。LLM 输出挂「AI 生成」。 |
| U4 | **呼吸预算** | 全页同时最多一组脉冲动画：声呐 ring、抓取 armed、置顶描边、回访展开互斥（由 U1 仲裁器兼管）；脉冲周期统一 1.8s ease-out。 |
| U5 | **长按统一 400ms** | 先览（B1）、抓取（③）、行业比（E3）、圈选（①）共用 `LongPressGestureRecognizer(400ms, 8dp 阈值)`，仅落点语义不同（07 号文档注册式手势）。 |

**视觉 token 统一**：就地气泡（圆角 14、brandBorder 描边、上浮 6px 淡入 220ms cubic-bezier(.2,.8,.3,1)）是**唯一**的就地回应容器——27 的声呐/圈选气泡与 28 的先览/摘要共用同一规格；卡片圆角 14/16 两档、阴影单一定义（`--shadowCard`）、动效时长只有 180ms（反馈）/ 280ms（展开）/ 500ms（FLIP）三档。

## 3. 共享基建（先于任何交互开发）

| 模块 | 职责 | 关键纯函数（可单测） | 估算 |
|---|---|---|---|
| `AnchorIndex` | timeline index ↔ 实体锚点的唯一映射器：句子 anchor（②）、新闻旗（B2）、公告锚（预留）、异动点（④）全部经它换算；跨日自动落到日K | `AnchorIndex.timeToIndex(t)` / `indexToTime(i)` | 1 人日 |
| `ContextChipStore` | 抓取上下文的唯一状态源：`Map<key, ChipRef(symbol, field, value, source)>`；输入栏 chips 与「问 AI」请求注入共用 | `ChipRef.toPromptFragment()` | 0.5 人日 |
| `RuleEngine` | 端侧规则模板的家：`AnomalyDetector`（④）、`MaterialityScorer`（F1）、`RelevanceRanker`（E1）、各卡 `Footnote` 函数、情绪词典（B1）——全部 `纯函数: (数据) → 文案/枚举`，规则名可回显（U3） | 各规则函数 | 3 人日 |
| `OverlayArbiter` | U1/U4 的执行者：浮层注册表 + 当前活跃层 + 空白点击关闭 + 脉冲预算 | `show/hide/currentLayer` | 0.5 人日 |
| `ChartGestureLayer` | 图表手势域：scrub（滑动）/ 长按圈选（①）/ 停顿计时（⑤）的状态机，输出几何/索引事件，不碰业务 | 状态机迁移表 | 1.5 人日 |
| `LongPressGestureRecognizer` | U5 的 400ms/8dp 识别器，业务方注册落点语义 | 阈值判定 | 0.5 人日 |

基建合计约 **7 人日**，先落地后，13 个交互平均每个 1–1.5 人日。

## 4. 分区开发规格

> 每个交互给最小可执行规格：触发 / 状态机 / 数据 / 组件落点 / 动效约束（Kuikly R1–R5）。重复的通用约束（U1–U5、R1–R5）不赘述。

### 4.1 A1 当初理由回访卡（Hero）
- **触发**：点「当初理由」行展开/收起；加自选后自动进 `watchlistEntry` 存储（时间、理由、当时价）。
- **状态机**：`collapsed ⇄ expanded`；状态词端侧判定：现价 ≥ 加自选价 → 「兑现中」；跌破加自选价 8% → 「已破位」（描述性措辞，禁止「应该/建议」）。
- **数据**：`WatchlistEntry`（已有 store）+ 历史行情取期间极值。
- **组件**：`RevisitCard`（Hero 下方）；展开动画 maxHeight 280ms（vif 挂载走 R4 两帧入场）。
- **验收**：展开/收起流畅；状态词与数据一致；`reason` 为空时显示「未写理由」而非隐藏入口。

### 4.2 B1 长按先览（弹幕带）
- **触发**：长按条目 400ms → `PreviewBubble`（U1/U5）。
- **数据**：`NewsItem` + 端侧摘要（标题关键词+首句截断）+ 情绪词典打分（利好/利空/中性 → 红/绿/灰点）。
- **组件**：`NewsTape` 加长按手势与气泡锚定；气泡消失：松手 700ms 后或点按条目。
- **验收**：长按不误触滚动（8dp 阈值）；情绪点颜色正确；无 LLM 调用。

### 4.3 B2 新闻旗标（弹幕带 ↔ 图表）
- **触发**：点按条目或旗 → 旗从图顶落到 `AnchorIndex(publishTime)` 对应位置（top 过渡 550ms 弹性曲线）；同时展开新闻摘要条（弹幕带下方，非全屏 Sheet）。
- **视觉**：旗色 = 发布后 1 小时真实涨跌（涨红/跌绿）；旗旁 300ms 延迟淡出反应标签（如 -1.12%）。**只述事实，不写因果**。
- **数据**：`NewsItem.publishTime` → index；跨日新闻落到日K（当前版本可仅支持分时内新闻，跨日置灰）。
- **组件**：`NewsFlagLayer`（ChartGestureLayer 之上的展示层）；`NewsSummaryStrip`。
- **验收**：旗位置与时间轴一致（单测 `AnchorIndex`）；重复点按收起；与声呐气泡互斥（U1）。

### 4.4 ④ 异动声呐（图表）
- **触发**：无；`AnomalyDetector.scan(timeline)` 启动时跑一次（放量倍数 ≥1.8、5 分钟 |涨跌| ≥0.8% 等阈值）。
- **呈现**：呼吸点（ring 脉冲 1.8s，U4 预算内，同屏 ≤3 点）；轻点 → 就地气泡（区间事实文案）+ 相关区间高亮带。
- **组件**：`AnomalyDetector`（RuleEngine）+ `SonarDot`（vif 挂载走 R4；ring 动画用两帧翻转预注册，R5）。
- **验收**：检测规则单测（构造放量/急跌样本）；气泡内容纯事实；reduced-motion 下 ring 不动画。

### 4.5 ① 圈选即问（图表）
- **触发**：图表长按 400ms（ChartGestureLayer，U5）→ 圈选态（顶部 hint 出现，十字线隐藏）→ 拖动画带 → 松手 ≥3 个点触发。
- **呈现**：带高亮（brand 12%）+ 就地气泡（区间起止、涨跌幅、极值、峰值量能倍数，全部端侧统计）；气泡内「去对话深聊」才跳页并携带区间上下文（走 ContextChipStore）。
- **状态机**：`scrub ⇄ select`（互斥，长按进入、松手退出）；误触 <3 点 toast 提示。
- **组件**：`CircleGeometry`（起止 x → index，纯函数）；复用 26 号 `crosshairIndex` 驱动链路，不新建驱动源（R1：圈选态只在 attr/event 闭包读）。
- **验收**：与 scrub/滚动无冲突；区间数字与行情源一致；气泡被 U1 仲裁。

### 4.6 ⑤ 十字线停顿预填（图表 ↔ 底栏）
- **触发**：scrub 停顿 600ms → 底栏问题灰字预填（措辞按走势方向模板生成）。
- **克制**：只预填不发送；恢复滑动即重算；离开 scrub 2s 清除；`q.pre` 样式与用户手打文字视觉区分。
- **验收**：永不自动发送；预填措辞覆盖涨/跌/横盘三模板。

### 4.7 ③ 抓取即上下文（指标 ↔ 底栏）
- **触发**：长按指标 400ms → armed（脉冲，U4）→ chip 跟手 → 落入输入栏热区（brand 描边反馈）。
- **降级路径**（工期紧先做这个）：长按不拖拽，chip 直接填入输入栏 + 推荐问句（1 人日）；完整拖拽版后续补（共 3 人日）。Kuikly 跨容器拖拽是已知难点， prototype 验证过交互，落地时优先保降级版。
- **数据**：`ContextChipStore`；「问 AI」发送时把 chip 拼进请求上下文。
- **验收**：chip 可点击移除；重复抓取去重；发送请求里能断言 chip 字段。

### 4.8 ② 句图联动（AI 解读 ↔ 图表）
- **触发**：点解读句 → 图表对应区间高亮 + 双向（scrub 图 → 相关句点亮，P1 可先做单向点句亮图）。
- **数据**：`InsightBundle` 协议加 `anchor:{start,end}`，**由端侧模板生成**（句槽位自带 timeRange），不让 LLM 猜坐标。
- **组件**：`AiInsightBlock` 渲染 on 态；高亮带复用 selBand（与①同容器，U1 互斥）。
- **验收**：anchor 与句子语义一致（抽检）；高亮带与圈选带样式区分（16% vs 12% 填充）。

### 4.9 E1 今日相关置顶（Bento）
- **触发**：进页时 `RelevanceRanker(insight, calendar, quote) → List<cardId>`（今日龙虎榜/新财报/资金连续异动等规则）。
- **呈现**：至多一张卡置顶（FLIP 500ms）+ brand 描边 + 「今日相关」角标；无事件日原序。
- **组件**：`BusinessInsightGrid` 排序入参；Kuikly 落地用 vfor key 重排 + transform 过渡（排序结果只在 vfor 闭包读，R1）。
- **验收**：Ranker 单测（构造事件日/无事件日）；每次至多置顶一张；重排不改卡片内容。

### 4.10 E2 卡内注脚 / E3 长按行业比（Bento）
- **E2**：每卡底部一行品牌色注脚（规则模板），点击 toast/气泡展示**判定依据**（U3）。
- **E3**：长按 400ms（U5）→ 卡内覆盖行业 Top5 横条（静态行业样本），松手 2.2s 后弹回；覆盖层只读。
- **验收**：注脚与卡片数据同源更新；行业比数据标注「端侧静态样本」。

### 4.11 F1 重要度徽章 / F3 多空平衡器（公告与研报）
- **F1**：`MaterialityScorer(title)` 三点评级（业绩/减持/回购/立案=高），高重要度整行加粗；点徽章显判定依据。
- **F3**：评级分布色带 + 滑块（step=评级组），拖动切观点摘要；摘要 = 研报标题改写，不生成观点。
- **验收**：评级规则单测；光谱两端「多/空」标注；无交易诱导文案。

### 4.12 G1 因子权重重放（涨跌归因）
- **触发**：拖动因子滑条（0–2.0×）→ 分解实时重算 `Σ 权重×因子贡献`。
- **克制**：顶部固定「数学重算，非预测」说明；复原按钮；残差=「未解释部分」如实展示。
- **验收**：重算结果与手算一致（纯函数单测）；松手不自动复原（保留用户探索态，复原按钮兜底）。

### 4.13 H1 加自选记一笔（顶栏）
- **触发**：点顶栏「＋」→ 快捷理由 chips（等回调/财报前布局/跟热点）浮出于底栏上方（U1 层）。
- **验收**：选择后写入 `watchlistEntry.reason` 并自动展开 A1 回访卡；可跳过（点空白）。

## 6. 克制预算（防"AI 大杂烩"）

- 一屏内 AI 元素 ≤ 3 个可见（当前页结构天然满足：声呐点、一行归因、解读卡不同屏共存时需检查）。
- 就地浮层同时 ≤ 1（U1）；脉冲同时 ≤ 1 组（U4）。
- 每个端侧文案 ≤ 40 字；每个气泡可 2 次点击内溯源（判定依据）。
- 新增任何第 14 个交互前，先回答：它属于「页面指给你看」还是「你指给 AI 问」？两者都不是则砍。

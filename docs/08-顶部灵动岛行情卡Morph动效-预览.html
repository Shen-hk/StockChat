四条设计约束

  • 图标位移必须快过容器边缘。opacity 在 150ms 归零、早于 transform 的 210ms——容器扩张到最宽之前图标已不可见，永不穿模。反向（淡得慢）会出现图标被黑底吞掉一半的粘连感。
  • 退场快、入场慢。展开时图标 210ms 加速离场，容器 560ms 从容铺开；收起时图标延迟 200ms 减速回归。先让路、再让位，视觉重心才落在行情卡上。
  • 只动 transform / opacity / filter。容器宽高不可避免触发布局，但内容用固定尺寸 + 父级裁剪规避回流抖动，GPU 合成层不重建。
  • 因果感来自"被顶开"。flex gap 让两个图标随容器边缘被动外移，是物理正确的因果；额外 32px 主动位移 + 模糊只是放大这个感受。可勾选上方"对照"验证差异。

核心结论

"功能太少"的病根不在 UI 简洁，而在于整个 App 只有"价格"一个数据维度。竞品的个股详情页有资金流、龙虎榜、股东户数、财报、公告、研报、分红、解禁、融资融券；股问只有快照 + 分时 + K 线。

更关键的是：立项文档里 "东财接口反爬已弃用"这条结论已经过期——今天实测东财三大接口族全部可用，数据层面的缺口可以低成本补上。

痛点 05 · 洼地中的洼地
复盘无沉淀 —— 散户到现在还要靠手工做台账
给散户的建议原文："每次买入前写清楚 3 个核心逻辑（行业景气度、公司业绩、买入估值），卖出时只核对逻辑有没有发生变化，不看当前盈亏"
这不正是 AI 该自动做的事？73% 散户亏损超 20% 后选择"躺平"，连续三年正收益的散户不足 8%（雪球整理）。易观千帆判定"投后管理是当前最明显的机会洼地"。

  • F8 全局搜索代码 / 名称 / 拼音 / 术语，替换占位

  • F13 解释深度三层一句话 / 一段话 / 带例子，长按切换
Later · 第三批
视工期 — 差异化深水区
  • F7 异动预警（应用内版）前台轮询 + 本地通知，压到 3 人日；预警文案直接带归因
  • F12 自选股增强自定义分组 + 异动标记
  • F11 财报 / 打新日历时间轴视图

最大风险：补功能破坏"克制"定位。 铁律 —— 新增页面必须有 AI 解读位，纯数据罗列的页面不做。判断标准很简单：同一个数据，竞品给数字，我们给数字 + "这意味着什么"。

6明确不做（防止范围蔓延）

每加一个功能前，先确认它不在下面这张表里。

⛔ Non-goals

选股器 / 条件选股 / "帮我选出 N 只"
中证协 2026-06 分级准入把「个股推荐、估值」列为高风险，应审慎评估展业风险
买卖建议 / 目标价 / 评级 / 买卖点
归因只解释已发生的事实与原因，不预测未发生的价格
社区 / 股吧 / UGC
与"信源降噪"定位直接冲突；雪球 AI 的失败就是信息茧房
实盘交易 / 条件单 / 模拟盘下单
合规红线 + Demo 范围
Level-2 / 逐笔 / 付费行情源
需付费授权，违背"公开免费数据做到 100% 真实"的架构主张
做一个"更差的东财"
补数据是为了给 AI 更多可解释的素材，不是为了堆数字
一条必须守住的产品原则：蚂小财的深度服务用户频繁交易比例下降 60%（证券时报 2025-06-23）。 这是"解释器"的北极星 —— 我们成功的标志不是用户交易更多，而是用户决策更好。任何会让用户"更容易冲动下单"的功能都不该做。

7需要拍板的三件事

这三条不定，第一批没法开工。
① 是否接受"先补数据维度，再补功能数量"的顺序？
这决定了第一批 2 周全花在详情页和数据源上，而不是做新页面。
② 市场总览页（F2）做成 App 首页还是二级页？
建议做二级页（聊天仍是主页），避免稀释"对话即入口"的定位。
③ F9/F10（持仓与交易台账）Demo 阶段只做概念卡，是否可以接受？
它们是长期护城河，但 Confidence 只有 0.5、Effort 大，与"先治骨感"冲突。

### 0.4 圆角与动效曲线

| Token | 值 | 用途 |
|---|---|---|
| `cardRadius` | 14 | 卡片 / 容器 |
| `inputRadius` | 20 | 胶囊按钮 / tab 组 / 涨幅 chip |

| 场景 | 曲线 | 时长 | 仅动画属性 |
|---|---|---|---|
| 颜色过渡（涨→跌） | ease-out | 200ms | `background-color`/`color` |
| Tab 滑动指示器 | `cubic-bezier(.34,1.56,.64,1)` spring | 280ms | `transform` |

## 1. 设计三原则（写功能前先立住）

| 原则 | 落点 | 反模式（不做） |
|---|---|---|
| **秩序 > 花哨** | 数字等宽对齐；每屏一个焦点数字（当前价）；section 间 24–32px 留白 | 花哨渐变、彩光、emoji 装饰 |
| **克制 = 护城河** | 不新增一个信息维度；每色有语义；红绿只表涨跌 | 堆砌模块、信息轰炸（moomoo 翻车） |
| **微交互 = 信任** | 所有按钮/tab/加载有反馈；颜色带 200ms 过渡 | 静态点击、无反馈的状态切换 |

> 金融 App 高级感第一性原理：**0.3 秒让用户觉得「这正规、我能掌控」** = 间距守恒 + 颜色克制 + 数字对得齐 + 动效有节奏。

### 2.1 断点（移动优先，从 320px 起）

| 断点 | 宽度 | 行为 |

## 4. 图表设计（分时 KuiklyChartKit + K线自研）

> ⚠️ **doc 18 的 §3 代码是 README 旧 API，已作废**。下方为**对照 `KuiklyTimelineChart.kt` 源码核实的真实 DSL**（已在 Kuikly 2.25.0 下 `:shared:compileKotlinJs` 编译通过）。

### 4.1 真实 DSL 要点（与 README 不符）

- 入口是 `AreaChart` / `BarChart` 等 `ViewContainer<*,*>` 扩展；调用须带 receiver：`container.AreaChart { }`。
- `attr { }` 内：`theme = ChartTheme.light().copy(...)`、`data(ChartSeries(...))`、`xAxis{visible}`、`yAxis{visible;includeZero;min;max;tickCount}`（**支持任意 min/max，非仅 includeZero**）、`line{smooth;showPoints;lineWidth}`、`area{fillColors=listOf(...)}`、`legend{visible}`、`grid{visible}`、`tooltip{enabled}`、`dataTransition{enabled;durationMs}`。
- 事件：`event { onItemSelected { sel -> sel.item.label / sel.item.y } }`。
- `BarChart` **没有 `barData`**（那是 `MixedChart` 的），副图用 `data(ChartSeries<BarEntry>)`。
- `interaction.maxRenderPointCount` 校验要求 `>=4`，分时点数可能不足 → **不设置**（走自动预算）。

### 4.2 昨收基准的处理（关键坑）

`AreaChart` 会**为每条 series 填到 0**，因此不能用「第二条恒定 series」画昨收基准（会填出一整块）。
**解法**：把 `yAxis` 范围**对称到 `previousClose` 上下**——`lo=min(prices.min, baseline)-pad`、`hi=max(...)-pad`，使昨收自然落在视觉中线；再配 caption「虚线为昨收基准」（库不暴露任意基准线，用对称范围 + 文字代替）。

### 4.3 已编译的真实调用骨架（节选自 `KuiklyTimelineChart.kt`）

```kotlin
// 主图：分时面积图（带 Tooltip / 数据过渡）
container.AreaChart {
    attr {
        height(height); marginTop(10f); alignSelfStretch()
        theme = timelineTheme                         // ChartTheme.light().copy(backgroundColor, axisColor, gridColor, labelColor, selectionColor)
        data(pointSeries)                             // ChartSeries(name, items=List<ChartPoint>, color)
        xAxis { visible = false }
        yAxis { visible = true; includeZero = false
                min = lo - pad; max = hi + pad; tickCount = 4 }
        line { smooth = true; showPoints = false; lineWidth = 2f }
        area { fillColors = listOf(fillColor) }       // 同色 ~20%α 填充
        legend { visible = false }; grid { visible = true }
        tooltip { enabled = true }
        dataTransition { enabled = true; durationMs = 420 }
    }
    event { onItemSelected { sel -> onPointSelected(sel.item.label, sel.item.y) } }
}
// 成交量副图（独立渲染，单色；BarEntry 不支持逐根染色）
container.BarChart {
    attr {
        height(56f); marginTop(6f); alignSelfStretch()
        theme = timelineTheme
        data(barSeries)                               // 注意：BarChart 用 data()，不是 barData()
        xAxis { visible = false }; yAxis { visible = false }
        legend { visible = false }
        bars { showValueLabels = false; cornerRadius = 2f }
        tooltip { enabled = true }
        dataTransition { enabled = true; durationMs = 420 }
    }
}
```

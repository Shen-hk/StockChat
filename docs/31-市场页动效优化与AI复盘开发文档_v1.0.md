## 0. 目标与边界

市场页此前有 11 条动效时间线（hero 入场、tick flash、情绪脉冲、热力图入场等），但 spec 22 勾选清单中仍有 4 条缺口未实现；「让 AI 讲讲今天」卡片是纯静态文案，没有任何点击行为，AI 能力完全缺席本次页面。

本次优化两件事：

1. **补齐 spec 22 缺口**：A2 宽度条中心生长（§3.3）、A3 量能柱生长（§3.2）、A4 梯队逐层升起（§4.6）、A1 指数带入场 stagger（§5.2 渐进加载的入场层）。
2. **AI 复盘卡（B）**：把静态卡升级为内联流式 AI 复盘——点击生成 → 思考态（骨架呼吸）→ 打字机流式输出 → 追问深链进对话页。这是 spec 22 §1 L3「触发一条 AI 内联归因」能力的页面级前置。

明确不做（克制原则）：不给装饰性 mini 趋势条加入场动画（不编码信息，违反 spec 22 §0 第一性原则）；不扩展 tick flash 到次级指数（同屏闪烁上限 §0.3）；不引入任何循环动效（AI 思考态是唯一的用户主动触发的等待反馈，且可随时中断）。

## 1. AI 复盘卡（B）设计

### 1.1 状态机

```
aiState: 0 idle → 1 thinking → 2 streaming → 3 done
                     ↑______________|          ↘ (重试/重新生成回 0)
任意 1/2 状态点击 = 中断（provider.stop()），有部分文本则落为 3，否则回 0
```

| 状态 | UI | 动效 |
|---|---|---|
| 0 idle | 副标题说明 + 右侧「生成」 | 无（卡片本体已有入场层） |
| 1 thinking | 两条与输出文本同构的骨架条 + 「正在汇总页面数据…」 | 骨架 opacity 呼吸脉冲（有限 2 次，键 `aiPulse`）；不 shimmer 循环 |
| 2 streaming | 正文打字机 + 尾随光标「▍」 | 流式本身即动效；光标随 `aiState` 切换挂载 |
| 3 done | 全文 + 右下「追问 ›」深链 | 无 |
| 4 error | 错误文案 + 「去 AI 对话页 ›」降级 | 无 |

### 1.2 数据链路

- 复用 `ChatDependencies.forPager(pagerId)` → `aiProviderFactory(config)` → `DeepSeekAiProvider.ask(messages, onDelta, onDone, onError)` 流式接口，与 ChatViewModel.askSubThread 同一模式。
- **未配置 API Key 时**（`config.validationError() != null`）不弹错误，直接 `openChatWithQuestion(...)` 跳对话页（那里有配置引导），与 RiskMapPage/StockDetailPage 的深链范式一致。
- Prompt 附带页面内全部已展示数据（指数、宽度、量能偏差、情绪分、封板率、连板高度、领涨板块、数据源戳），要求 ≤150 字纯文字复盘、不输出卡片协议、禁止荐股措辞。
- 输出落地时脚注固定展示「数据源 + AI 输出仅供参考」免责行。

### 1.3 Kuikly 响应式合规（R1–R5）

- `aiText` / `aiState` 是 observable，streaming Text 的 `attr {}` 内读取（R1）。
- onDelta 回调里直接追加 `aiText`（与 ChatViewModel 同线程假设）。
- 打字机 Text 不包 vbind——attr 内读 `page.aiText`，每次 delta 重跑 attr 更新文本，视图不重挂（避免 R4 两帧问题）。
- 骨架呼吸：`aiPulse` 有限翻转驱动 opacity，`animate(Animation.easeOut(0.5f), page.aiPulse)` 最后注册（R2/R5）。
- 流式→完成切换走 vif 重挂（新挂载不做动画，可接受——文本内容变化本身就是反馈）。

## 2. 动效补齐规格

### A1 · 指数带入场 stagger（新增 `stripEntered`）

| 参数 | 值 |
|---|---|
| 触发 | `created()` 里与 hero/ladder 同一帧 setTimeout(1) 置 true |
| 每张卡 | opacity 0→1 + translateY 12px→0，260ms ease-out |
| stagger | 60ms × index |
| reduce-motion | 直接显示，不注册动画 |

实现要点：scale+translate 必须用**全参** `transform(rotate=Rotate.DEFAULT, scale=…, translate=Translate(0f,0f,0f,y), anchor=Anchor.DEFAULT, skew=Skew.DEFAULT)`——便捷重载 `transform(scale=…)` 会把其它分量重置为 DEFAULT，互相覆盖。

### A2 · 宽度条中心生长（spec 22 §3.3，新增 `breadthEntered`）

| 参数 | 值 |
|---|---|
| 整条比例条 | scaleX 0→1，520ms ease-out，transform-origin 中心（Kuikly 默认）——两段同时生长，同一个事实的两面 |
| 中央「红盘 x%」数字 | opacity 0→1，300ms，delay 360ms（≈条生长到 70% 时） |
| 数据刷新 | 包在 `vbind({ overview })` 内重建；重建后 entered 已为 true，瞬移到目标态，不重播 |

### A3 · 量能柱生长（spec 22 §3.2，新增 `volumeEntered`）

| 参数 | 值 |
|---|---|
| 三根柱 | width 0→目标，320ms ease-out，stagger 40ms（今日→昨日→5日均） |
| 数据刷新重建后 | 不重播（同 A2 理由） |

width 是普通 attr 值，Kuikly 的 animate 会补间该 attr 变化（与既有 L2 封板率背景色补间同机制）。

### A4 · 梯队逐层升起（spec 22 §4.6，改造既有实现）

| 参数 | 值 |
|---|---|
| 旧实现 | scale 0.96→1 + 淡入，delay 按**高板→首板**顺序 |
| 新实现 | opacity 0→1 + translateY 12px→0，280ms ease-out，delay = 60ms × (level−1)，**首板→高板**逐层升起（与梯队高度的空间隐喻一致） |
| 展开/选中反馈 | 保留原 scale 1.03 反馈不动 |

### B 卡入场

AI 卡随 `stripEntered` 同批淡入上移（delay 放最后）。

## 3. 验收清单

- [ ] AI 卡：无 Key 点击 → 跳对话页；有 Key → 思考态骨架呼吸 → 流式输出 → done + 追问深链
- [ ] 流式过程中再点 = 中断，保留已生成部分
- [ ] reduce-motion 开启：AI 卡点击后无骨架动画（直接 thinking 文案 + 流式），四条入场动效全部瞬时到位
- [ ] 下拉刷新/数据更新：A2/A3 不重播入场（vbind 重建 + entered 恒真）
- [ ] 梯队顺序：视觉上首板先出现
- [ ] `ArchitectureBoundariesTest` 通过（未新增跨层依赖）
- [ ] 主题：Dark/Light 均检查骨架条与 AI 卡配色（用 `brand/brandSoft` token，不硬编码）

## 4. 风险与后续

- DeepSeek 流式回调线程若非 UI 线程，observable 写入需对齐 ChatViewModel 的既有假设（同链路已在生产使用，风险低）。
- 后续可做：spec 22 §4.2 下钻共享元素转场、§3.1 分时 draw-on（Canvas strokeEnd）、AI 复盘与 L3 异动归因打通（封板率跌破 80% 时自动生成一条归因行）。

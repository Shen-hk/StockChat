# 20 · 市场界面重构设计方案 v2.0

> 状态：设计定稿 · 2026-09-02 · **取代 v1.0**（v1.0 因缺调研依据、信息不周全、无动效规格、AI 味过重被否）
> 依赖：doc 21（竞品调研与信息架构 · 前置依据）、doc 22（动效与交互规范 · 26 条参数）、doc 19（权威色彩 token）
> 原型：`docs/22-市场界面重构-原型v2.html`（1440 展示台 · 真实 2026-09-02 收盘数据 · 四视图）

---

## 1. 现状诊断

现有 `MarketPage.kt`（约 640 行）结构：一张白色情绪卡 → 两排 tile 网格 → **5 张等高同构板块卡**。三个问题：

1. **纯卡片堆叠**，z 轴只有一层，是廉价感的头号信号；与项目已建立的玻璃材质长板（doc 08/16/19）断裂。
2. **信息不周全**：无量能、无时段态、无涨停/封板率/连板梯队（A 股最核心的情绪指标）、无资金、无日历。
3. **关系靠罗列**：涨跌家数、板块排名这类本质是「关系」的数据，被拆成一堆并列数字，用户要自己在脑子里做比较。

---

## 2. 五条设计原则

| # | 原则 | 落地判据 |
|---|---|---|
| 1 | **层叠 > 堆叠** | 同屏至少 4 个 z 深度；禁止出现 3 张以上等高同构卡 |
| 2 | **数字即焦点** | 主数字 ≥30px/800 字重；走同花顺路线（数字大、单屏模块少、层级深），不走东财路线（密、小、平） |
| 3 | **关系用图说话** | 涨跌 → 中心分界比例条；名次 → 等级条；梯队 → 层宽 + 昨日虚线残影；强度 → 明度色阶 |
| 4 | **克制在层级，不在信息量** | 第一级 9 区块只放「定性 + 3 个数」，深度全部下沉第二级；砍掉 8 类工具型模块（doc 21 §3.3） |
| 5 | **AI 是注解，不是贴纸** | 全页 AI 元素 ≤5 处，形态为内联文字；视觉黑名单 9 项零容忍（doc 21 §4） |

## 3. z 轴层叠视觉系统

```
z0  氛围底      随情绪冷暖的双径向渐变，高 430px，不可交互
z1  次级面板    深证/创业板衬后卡、板块 #2–6 榜单容器（opacity .9，无 blur）
z2  常规区块    量能条、宽度条、资金三行（surface + 1px divider + sh1）
z3  主卡玻璃    上证主卡、情绪四维面板、板块 #1（glass + blur20 + sh3）
z5  浮层        长按 peek（吸顶指数条已并入 AppTopBar 滚动紧凑态，非独立浮层，见 doc 22 §4.4）
```

**造景深的手法**：负边距重叠（`idx-main` 上移 −22px 压住衬后卡）+ 极轻漫射阴影（三级 sh1/sh2/sh3）+ 顶部 1px 高光发丝边。
**禁止**：靠加更多盒子、加边框粗细、加饱和色来造层次。

## 4. 九区块详规

> 完整字段与口径见 doc 21 §3.1；动效编号见 doc 22 §8。

**A 时段状态条**（常驻，决定下方所有模块的呈现态）
圆点 + 时段名 + 右侧刷新说明。盘中圆点带 2s 扩散环；非交易时段为灰点且整页降饱和 55%。8 种时段态见 doc 21 §5。

**B 情绪定性 Hero**
无卡片，文字直接落在氛围底上。30px/800 的一句定性（如「指数与情绪双杀」），关键词用语义色。下方 pill 组：情绪周期 / 恐贪指数 / 关口状态。**紧随一行 AI 内联注释（全页唯一常驻 AI 元素）。**

**C 指数带**
上证主卡玻璃浮起（38px 点位 + 分时 draw-on + 成交/最高/最低），深证与创业板衬后造景深，下方横滑 chip 带 6 个（科创50/北证50/沪深300/上证50/中证500/恒生）。逆势指数（如北证50 +2.50%）chip 加语义色描边——**这类信号只在完整指数带里可见，v1.0 只放三大指数会漏掉。**

**D 量能条**
27px 主数字（1.79 万亿）+ 缩放量差 + 5 日均值偏离%。三条对比条：今日 / 昨日 / 5日均，实心条只给今日。条件 AI 注释：区分「退潮缩量」与「底部地量」。

**E 市场宽度**
左涨右跌两个 25px 数字向内收，中间放红盘率。下方中心分界比例条（涨/平/跌三段），legend 给涨跌差、涨幅>5%、跌幅>5%、平盘。

**F 短线情绪四维**
**单块玻璃面板 + 发丝竖线分隔四栏**，不是四张卡。涨停 / 跌停 / 封板率 / 最高板，每栏带次要说明（一字 8 只、昨日 0 只、炸板 14 只、昨 7 板）。封板率与最高板命中 L2 → 触发脉冲。标题带「口径」角标可点。

**G 连板梯队**
顶部一条虚线残影标昨日高度（7板）与坍塌幅度；下方每层用**条宽编码家数**，4板/3板/2板/首板逐层排列，点击展开该层说明。这是全页最能体现「解释器」定位的区块——梯队的**形状**比任何单个数字都直观。

**H 板块**
三切页「领涨 / 领跌 / 热力图」。领涨 = #1 玻璃面板浮起（板块名 + 涨幅 22px + 成交额/涨停数/主力净流入 + 领涨股 chip）+ #2–6 等级条榜单衬后。热力图 16 格，色阶只用明度编码强度。条件 AI 注释：主线切换判定。

**I 资金三行**
北向（沪深股通分拆 + 占成交比）/ 行业主力进出 Top / 龙虎榜机构 vs 游资。标题角标标注**口径冲突**（北向存在 −66.14 亿与 −402 亿两个流传口径）。

**收口**：底部「让 AI 讲讲今天」一处 + 数据来源与免责说明。

## 5. 首页 AI / 市场 双模

**MarketSnapshot(theme, snapshot, onAsk) = A + B + C + D + E**（时段 + 定性 + 指数 + 量能 + 宽度），市场页与首页市场模式共用同一组件。

- **不含个股与板块名称**：首页是会话入口，出现个股名 → 用户点击 → 滑向「推荐」语义，触碰中证协 2026-06 分级中的高风险格。
- **切换不丢 AI**：两模共用同一句大盘定性文案，切换时该句**原位保留**（共享元素转场 380ms）；市场模式底部保留 AI 收口行。
- **默认态按时段**：盘中默认「市场」，非交易时段默认「AI」；用户手动切换后记住选择。
- 范式依据：IBKR Mobile 的 Markets 页顶部即 `Markets | News` 双 tab（doc 21 §1.3）。

## 7. 验收标准

**视觉**
- [ ] 同屏 z 深度 ≥4；无 3 张以上等高同构卡；无 tile 方阵
- [ ] 主数字 ≥30px/800；等宽数字，数值变化零布局抖动
- [ ] 未引入 doc 19 之外的任何饱和色；平盘/停牌/非交易时段统一用 flat 灰

**信息**
- [ ] 9 区块齐备；情绪类数字均带可点口径角标
- [ ] 8 种时段态均有独立呈现（含静默期「非故障」提示、竞价前 5 分钟虚假大单警告）
- [ ] 北向资金口径冲突已显式标注

**AI**
- [ ] 全页 AI 元素 ≤5（常驻 1 + 条件 3 + 收口 1），且 ≥4 处为内联文字
- [ ] 视觉黑名单 9 项零命中
- [ ] 行情平静时（无阈值触发）整页 AI 元素 = 1

**动效**（doc 22 §8 全 26 条）
- [ ] tick flash 600ms 三段，同元素 <200ms 合并
- [ ] 成交量类渲染 500ms 节流合并
- [ ] 同屏并发动画 ≤8，超出按显著性降级
- [ ] 「减少动态效果」开启 → 22 条位移/缩放降级，保留 4 条颜色变化
- [ ] 午休/休市循环动效全停

**合规**
- [ ] 无买卖建议、目标价、评级、仓位建议
- [ ] 全部文案为可陈述事实问法（是多少 / 为什么 / 什么意思），无「怎么选 / 该不该买 / 推荐」
- [ ] 底部数据来源与免责常驻

**性能**（doc 22 §7）
- [ ] 骨架 <120ms，缓存 <300ms，实时 <1.2s，滚动稳定 60fps

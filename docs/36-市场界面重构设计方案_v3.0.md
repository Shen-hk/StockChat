## 1. 诊断：为什么按 doc 20 v2.0 落地后，页面仍然是「纯信息流」

doc 20 v2.0 解决了「卡片同构、层次扁平、信息不周全」三个问题，但落地后用户的主观感受仍是**信息流**。根因不在视觉层，在**信息架构层**：

1. **按数据类型组织，不按用户问题组织。** 量能 / 宽度 / 短线情绪 / 梯队 / 板块 / 资金——这是**报表的目录**，不是散户的问题。用户打开市场页想回答的是三句话：「现在什么情况？」「今天经历了什么？」「谁在领涨、为什么？」——九区块把这三个答案拆成九段并列的纵向长图。
2. **全部区块等权等节奏。** 每段都是「标题 + 副标题 + 卡片」，LDRS 打分里「节奏」（doc 24）不达标：视线从上到下匀速滑过，没有主次锚点，也没有记忆点——F 型扫完，什么都没记住。
3. **数据全是「现在时」（doc 33 已诊断）。** 页面是最新一帧照片，而用户 62.4% 的第一需求是「盯盘异动」（易观 2026Q1）——异动是**时间的概念**，「刚才发生了什么」在这页上无处可答。

**结论**：v3.0 不再往流里加组件，而是**换骨架**——从「九区块报表流」换成「一天的市场纪录片」。

| 痛点 | 证据 | 本方案的回应 |
|---|---|---|

## 3. 新信息架构：纪录片三层结构

```
┌─ 第一层 叙事层（故事，约 1.5 屏）─────────────────┐
│  Hero 定性 + 温度计 + 主指数玻璃卡                  │
│  ★ 叙事轴（全页脊柱：多空发散面积 + 事件钉 + 成交密度）│
│  关键时刻横滑卡（≤6 张，点卡跳帧）                   │
│  AI 可导航复盘（句子 ↔ 轴双向点亮）                  │
├─ 第二层 数据切片层（一个容器，四选一）───────────────┤
│  [宽度情绪] [量能资金] [板块竞速] [连板梯队]          │
│  —— segmented 常驻吸顶，同屏永远只见一个切片，       │
│     全部随 scrub 帧同步                             │
├─ 第三层 口径层（收口，常驻）────────────────────────┤
│  口径角标 · 样本标注 · 数据来源戳 · 免责             │
└──────────────────────────────────────────────────┘
```

**与 v2.0 九区块的映射**：

| v2.0 区块 | v3.0 去向 |
|---|---|
| A 时段状态条 | 保留原位（叙事层顶部） |
| B 情绪定性 Hero | 保留，右侧升级温度计徽章（⑥）+ 日内温度轨迹 mini 曲线 |
| C 指数带 | 保留在叙事层（时间机器的作用面，全部随帧更新） |
| D 量能 / E 宽度 / F 情绪四维 | 合并进切片层「宽度情绪」「量能资金」两个切片 |
| G 连板梯队 | 切片层「连板梯队」 |
| H 板块 | 切片层「板块竞速」（⑤，取代三切页；领涨领跌并入竞速场排序） |
| I 资金 | 切片层「量能资金」（北向随帧更新 + 口径角标保留） |
| AI 复盘卡 | 升级为可导航复盘（④），仍全页唯一常驻 AI 触点 |

**结构判据（替代 v2.0 验收的视觉条目）**：
- 叙事层之外，同屏纵向卡片数 **≤2**（切片容器 + 收口说明）；v2.0 是 7 张。
- 首屏必须出现且只出现一个「绝对主视觉」：叙事轴。
- 任何数字都能回答「当时呢？」——拖到那一刻，全页一致（宪章六：可回放）。

## 4. 交互总纲：一切围绕 scrub

1. **scrub 是页面级手势**：拖动叙事轴 = 拖动整个市场（②时间机器）。指数带、温度计、宽度、情绪四维、量能、北向、竞速场、梯队全部同帧更新。
2. **回放态三重防误读**：顶部「正在看 HH:MM 的市场 · 历史回放」品牌色水印 chip + 「回到现在」按钮；全页降饱和 5%；轴上游标常驻。绝不把历史当实时。
3. **度量切换**：叙事轴默认全市场红盘率口径，可切上证 / 创业板 / 北证50（分界线随口径变化：50% ↔ 昨收 0%）。市场 ≠ 上证单一指数，「北证50 逆势走强」只在多口径下可见。
4. **只回放已发生事实**（doc 33 §8 沿用）：事件检测全部端侧规则（EventDetector，阈值沿用 doc 21 §4），AI 只把事件串成话，不发现事件、不预测。

## 5. 动效规格 v3 增补（叠加在 doc 22 的 26 条之上）

| 编号 | 项 | 规格 |
|---|---|---|
| N1 | scrub 帧同步 | 拖动中**全部数字直接切换、零补间零动画**（doc 22 §0.2 等宽防抖动）；松手回弹到整分钟；循环动画（呼吸点/流光）在 scrub 开始即停 |
| N2 | 时刻卡跳帧 | 补间驱动单一 `scrubMinute` observable，520ms `cubic-bezier(.32,.72,0,1)`；途中不触发任何中间态动画 |
| N3 | 回放水印 | 240ms 淡入 + 8px 下移（`ease-out`）；降饱和 900ms（与 doc 22 §5.3 时段切换同参数——同属「氛围」变化） |
| N4 | 竞速场超车 | 位次重排 260ms 补间；超车行品牌色闪动 500ms 一次（`keyframe` 峰值 opacity .14）；实时态箭头静默 |
| N5 | 叙事轴入场 | 描边 draw-on 680ms（继承 §3.1 分时范式），面积填充延迟 60%，事件钉 stagger 40ms 弹出（scale .6→1） |
| N6 | 切片切换 | 交叉淡入 + 4px 位移 200ms（继承 §4.4 顶栏紧凑态范式）；**禁止高度动画**（防回流抖动）；宽度条在切片首次呈现时按 §3.3 双向生长（每会话一次） |
| N7 | 温度计 | 徽章数字随帧直切；点开分量拆解 320ms 高度展开 + 内容延迟 80ms 淡入（§4.6 梯队展开范式） |
| 兜底 | 减少动态效果 | N2–N7 全降级为瞬时切换；scrub 本身保留（用户主动手势，且是信息本体） |

**性能预算**（继承 doc 22 §7）：scrub 帧率 ≥55fps；同屏并发动画 ≤8；切片非可视时该切片刷新暂停。

## 6. 合规与 AI 预算

- AI 触点仍 ≤5：常驻 = 可导航复盘卡 1 处（收口行计入）；事件钉/时刻卡是端侧数据标记，不算 AI。
- 复盘句锚点由端侧模板生成（句子槽位自带 timeRange，事件流填充），LLM 只润色措辞、不发明坐标——27② 已验证的 anchor 机制，单位改为分钟索引。
- 温度计措辞红线：只说市场温度，禁「评分 / 等级 / 匹配 / 你的风险」词表（doc 23 合规铁律 2）；公式全透明，与开盘啦黑箱温度划界。
- 全部回放只覆盖已发生事实；无事件日不显示时刻卡（铁律：条件触发不常驻）。

## 9. 增补：新闻弹幕带与指数下钻（2026-09-09 第二轮反馈）

### 9.1 J1 今日新闻弹幕带（NewsTape 市场页版）

- **位置**：叙事层最顶部（时段条上方），无标题栏、无卡片壳——纯弹幕 3 泳道匀速横滚，直接落在氛围底上
- **动效**：线性匀速滚动（新闻之间无显著性差异，不得抢叙事轴的主视觉）；hover / 触摸按下暂停泳道便于阅读；「减少动态效果」降级为静态标签流
- **与时间机器联动（本组件的差异化点）**：回放到 HH:MM 时，弹幕带**只显示该时刻前发布的新闻**——新闻也是「当时的事实」，回放态不允许剧透未来；回到现在恢复全量
- **点击**：以该新闻为上下文追问 AI（复用 `openChatWithQuestion`，正式版跳聊天页；原型以 toast 示意追问路径）
- **合规**：新闻条目为事实陈述，不计入 AI 触点；正式版每条带来源与时间戳

### 9.2 J2 指数下钻（跳转既有界面，不新建）

- hero 主位数字与任一指数 chip **点击跳转 App 已有的大盘详情页**（市场页侧不新建界面，转场沿用现有 openPage 路由）
- 唯一新增约定：跳转时若市场页正处于历史回放态，传递当前帧上下文（详情页按该帧展示或忽略——评审时定）
- 原型中以 toast 示意跳转路径，不重复实现详情页

**增补验收**
- [ ] 弹幕带随帧过滤正确（回放 10:42 不出现 10:42 之后的新闻）；rm 降级为静态流
- [ ] 指数主位与 chip 均可跳转既有详情页；AI 触点计数不变（弹幕带点击是导航不是 AI 输出）

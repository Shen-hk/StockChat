# 20 · 市场界面重构设计方案 v1.0

> 页面：`MarketPage`（`shared/src/commonMain/kotlin/com/kuikly/stockchat/page/MarketPage.kt`，130 行）
> 目标：把市场页从「一张白卡 + 两排 tile + 五条等高板块卡」升级为「有 Z 轴层次、安静可控的市场概览舱」——**不用卡片堆叠，用玻璃层叠**。
> 约束：① 不新增任何信息维度（克制 = 护城河）；② 配色严格沿用 doc 19 §0 权威 token；③ 红绿只表涨跌，深蓝只表 App/AI；④ 为「首页 AI / 市场 双模」预留可复用组件。
> 配套原型：`docs/20-市场界面重构设计-预览.html`（市场页 + 首页·市场模式 双视图，深浅色可切）
> 出品：2026-09-02

---

## 0. 为什么重构（现状诊断）

`MarketPage.kt` 当前是**纯卡片堆叠**，没有任何层次：

| # | 现状 | 问题 | 代价 |
| - | --- | --- | --- |
| 1 | 顶部一整张 `surface` 白卡装情绪分 + 解释 + 信源 | 大白块压在 `page` 底色上，无深度、无氛围 | 首屏像「设置页」而非「行情舱」 |
| 2 | 「三大指数」= 3 张等宽 `MetricTile` 横排 | 三张一样大，没有主次；上证作为「市场门面」被淹没 | 用户分不清该先看谁 |
| 3 | 「市场宽度」= 4 张 `MetricTile`（上涨/下跌/涨停/跌停） | 四个孤立数字，丢掉了「涨跌家数之差」这个最有信息量的关系 | 数据密度高但**信息量低** |
| 4 | 「领涨板块」= 5 张**等高同构** `surface` 行卡 | 五张一模一样，#1 领涨股和 #5 毫无区别 → 清单感、廉价感 | 这是 AI-slop 头号信号（identical card grid） |
| 5 | 全页所有容器都是 `surface` 实底 + `borderRadius` | 没有玻璃、没有透明、没有重叠 → 完全扁平 | 与项目玻璃长板（顶栏岛 / 输入栏 / 详情页）断裂 |

**根因**：市场页被当成「另一张列表页」实现，而不是「用深度讲清楚今天市场发生了什么」的概览舱。

**目标**：用**层叠（layering）**替代**堆叠（stacking）**——同一屏里，玻璃面板浮在不同 Z 深度，数字有主从，关系用可视化表达，而不是用更多盒子。

## 1. 设计五原则（写功能前立住）

| 原则 | 落点 | 反模式（不做） |
| --- | --- | --- |
| **① 层叠 > 堆叠** | 玻璃面板靠 z 轴深度 + 负边距重叠 + 极轻漫射阴影分层；不是用更多实底盒子 | 5 张等高同构卡、tile 方阵 |
| **② 数字即焦点** | 每区一个「焦点数字」（上证指数 / 情绪分 / 宽度差），其余降级为次级字号 | 所有数字同字号同色 |
| **③ 关系用图说话** | 涨跌家数 → 比例条；名次 → 等级条；趋势 → spark | 把关系拆成 4 个孤立 tile |
| **④ 克制 = 护城河** | 不新增信息维度；红绿只表涨跌；深蓝只表 App/AI；保持解释条 | 堆模块、信息轰炸（moomoo 翻车） |
| **⑤ 微交互 = 信任** | 复用 doc 19 四个签名动效；颜色带 200ms 过渡；「问 AI」桥处处可达 | 静态点击、无反馈的状态切换 |

> 市场页高级感第一性原理（同详情页）：**0.3 秒让用户觉得「这正规、我能掌控、今天发生了什么一目了然」** = 间距守恒 + 颜色克制 + 数字对得齐 + 层次看得见 + 动效有节奏。

## 2. 信息架构（竖向结构 A–G，移动优先）

```
┌─ 顶栏 AppTopBar（玻璃态；左返回 · 中「市场 / 数字之后，解释今天发生了什么」· 右 热点 / 日历）
├─ 情绪氛围底（tonal backdrop，钉在顶栏下、随滚动视差，峰值 ≤10%）         ← 氛围层 0
├─ Scroller（paddingTop = 状态栏 + 73；paddingBottom = 88）
│   A. 情绪 Hero（浮动玻璃面板，负边距叠在氛围底上）                        ← 焦点层 5
│      市场情绪 N 分 · 偏暖/偏冷 · 情绪条 · 一句话解释 · 数据源·时间(脉冲点) · [问 AI 今天情绪]
│   B. 三大指数（主从分层，非三张等卡）
│      主：上证指数（大号 + 涨幅 chip + 极简分时 spark）浮起
│      次：深证成指 / 创业板指（成对衬在主卡之后，缩小、降透明度，造深度）
│   C. 市场宽度（单条比例条，非 4 卡）
│      上涨/下跌/涨停/跌停 堆叠比例 + 刻度 + 下方 4 个数字（纯文本，非卡）
│   D. 领涨板块（分层榜单，非 5 等卡）
│      #1 特色玻璃面板（名 + 涨幅 chip + 主力净额 + 成分广度 spark + 问 AI）
│      #2–5 紧凑排名行（左侧等级条长度编码名次 + 发丝分隔，非卡）
│   E. 资金视角（玻璃 slim strip，2–3 项：北向 / 主力净流入 / 成交额的相对位）
│   F. 异动聚焦（连板高度 Top / 涨停封单，复用 D 的排名语言，保持同质列表才用卡组）
│   G. 解释条（领涨不代表追入 · 板块页继续拆解）— 合规必须保留
└─ 浮钮（玻璃）：右下「问 AI ↗」（品牌色描边，触发对话「今天市场怎么看？」）
```

> **丰富性从哪来**：E（资金视角）+ F（异动聚焦）是新增区块，但**不新增信息维度**——它们用的都是 doc 19 已确认的东财字段（北向、主力净额、连板高度），只是把原来平铺的字段改成有层次的呈现。

## 3. 层叠视觉系统（z 轴、玻璃深度、氛围底）

### 3.1 Z 轴分层契约（全页唯一真值）

| 层 | 元素 | 深度做法 |
| - | --- | --- |
| 0 | 情绪氛围底 | 钉顶栏下，`position` 固定区；随滚动 `translateY(0.4×)` 视差；峰值透明度 ≤10% |
| 1 | 氛围底上的极轻网格/光晕 | 仅 ≤6% 透明度，绝不与内容抢戏 |
| 2 | 次级面板（深证/创业板、排名行） | `surface` 实底 + `divider` 发丝边，正常阴影 |
| 3 | 主卡（上证、领涨 #1） | 玻璃 `theme.glass` + `blur(20)` + 1px 高光边 + 极轻漫射阴影，**负边距叠在氛围底/次级之上** |
| 5 | 浮钮「问 AI」 | 玻璃 + 品牌色描边，常驻右下，z 最高 |

> 层次感来自**同一屏里不同面板处于不同深度**，而不是「再垫一个盒子」。次级面板压在主卡之后（translateY + 缩小 + 降透明度），制造景深。

### 3.2 玻璃深度 Token（新增，复用 `theme.glass`）

| Token | Light | Dark | 用途 |
| - | --- | --- | --- |
| `marketGlass` | `rgba(255,255,255,0.72)` + `blur(20)` + `saturate(1.4)` | `rgba(29,29,31,0.66)` + `blur(20)` | 主卡 / Hero / 浮钮 |
| `marketGlassBorder` | `rgba(255,255,255,0.6)` | `rgba(255,255,255,0.10)` | 玻璃高光边（1px） |
| `marketGlassShadow` | `0 8px 30px rgba(20,30,50,0.08)` | `0 8px 30px rgba(0,0,0,0.40)` | 极轻漫射（不黑重） |
| `marketBackdropWarm` | `radial-gradient(80% 36% at 50% 14%, rgba(217,46,46,0.07), transparent 70%)` | `rgba(255,120,120,0.09)` | 偏暖（情绪 ≥50） |
| `marketBackdropCool` | `radial-gradient(80% 36% at 50% 14%, rgba(12,122,69,0.07), transparent 70%)` | `rgba(84,214,166,0.09)` | 偏冷（情绪 <50） |

> 玻璃参数与 `AppTopBar` / 输入栏胶囊**同一套材质系统**（doc 19 已落地的 `GlassBackdrop` / `GlassTokens`），不另起炉灶。

### 3.3 配色铁律（沿用 doc 19 §0.1，不新增饱和色）

- 品牌深蓝 `#1E5BD6` 只出现在：顶栏进度/「问 AI」/ 浮钮描边 / 焦点数字脉冲——**绝不在红绿语义上**。
- 涨 `#D92E2E` / 跌 `#0C7A45` 只表市场数据涨跌。
- 情绪条的色随分数走涨/跌语义（≥50 偏暖红系，<50 偏冷绿系），这是市场数据，不是品牌。

### 3.4 字体 / 间距（沿用 doc 19 §0.2 / §0.3）

- 数字一律 `tabular-nums`（等宽），避免视觉跳变。
- 焦点数字：`display 40`（上证价 / 情绪分）；次级 `body 14` / `sm 13`；元信息 `label 11` / `meta 10`。
- 间距走 `theme.spacing`（区块间 `x3/x4`，卡内 `lg`）。

### 3.5 动效曲线（沿用 doc 19 §0.4）

| 场景 | 曲线 | 时长 |
| --- | --- | --- |
| 颜色过渡（涨→跌 / 暖→冷） | ease-out | 200ms |
| 面板入场 | `cubic-bezier(.16,1,.3,1)` ease-out-expo | 280ms |
| 顶栏进度条 | 线性（随滚动） | — |
| 实时脉冲点 | linear 循环 | 1200ms |
| 氛围底视差 | 随滚动 `translateY(0.4×)` | — |

> 克制：单屏同时动效 ≤3；只动 `transform`/`opacity`；`prefers-reduced-motion` 全量降级为终态（视差停、脉冲停、入场直接显）。

## 4. 区块详规（A–G，含状态）

### A. 情绪 Hero（浮动玻璃面板）

- 容器：`marketGlass` + `marketGlassBorder` + `marketGlassShadow`；**负 margin-top（−20px）叠在氛围底上**，z=5。
- 左：情绪分 `display 40` `ink-1` + 标签「偏暖 / 偏冷」`meta` `ink-3`；右侧情绪条（86×8，`surfaceMuted` 底 + 分数比例填充，色随暖/冷）。
- 解释：`body/12.5` `ink-2` 行高 1.5，一句话讲清今天情绪（来自 `MarketOverview.explanation`）。
- 信源行：`meta` `ink-3`，前接 8px 实时脉冲点（「更新于 16:14」）。
- 右下小玻璃按钮「问 AI 今天情绪」→ 触发对话「今天市场情绪偏暖，主要因为什么？」。
- **状态**：`loading`（骨架条）/ `warm`（≥50）/ `cool`（<50）。

### B. 三大指数（主从分层，非三张等卡）

```
┌──────────────────────────────────┐
│ ╭─ 上证指数（主卡 · 玻璃 · 浮起）─╮ │
│ │ 3,218.74   ▲ +0.62%          │ │
│ │ ── 极简分时 spark（brand 40%α）│ │
│ ╰────────────────────────────────╯ │
│   ╭─ 深证成指 ─╮ ╭─ 创业板指 ─╮    │ ← 次卡，衬在主卡之后，缩小降透明
│   │ 10,156 +0.3%│ │ 2,034 −0.4% │   │
│   ╔════════════╝ ╚══════════════╗  │
└──────────────────────────────────┘
```

- 主卡「上证指数」：玻璃、`display 40` 价、涨幅 chip（`rise/fall-soft` 底）、极简分时 spark（SVG 100×24，`brand` 40%α）。
- 次卡「深证 / 创业板」：成对，`surface` 实底 + `divider`，价 `body 14`、`sm` 涨幅；**translateY(+8) + scale(.96) + 透明度 .9 衬在主卡之后**，制造景深。
- 每卡可点 → 进入 `StockDetailPage` 或触发「上证指数今天为什么涨？」。
- **状态**：`loading` / `rising` / `falling` / `flat`。

### C. 市场宽度（单条比例条，非 4 卡）

```
┌────────────────────────────────────────────┐
│ SectionLabel：市场宽度 · 看多少股票真正参与上涨  │
│ ▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░░░░░░░░░░░░░░░░░░░░░░░ │ ← 单条比例
│ ▔涨停▔▔▔▔▔上涨▔▔▔▔▔▔▔▔▔▔▔下跌▔▔▔▔▔▔▔▔▔跌停▔ │   刻度锚点
│ 上涨 2,841 家   下跌 1,932 家              │ ← 纯文本，非卡
│ 涨停 63 只     跌停 12 只   涨跌差 +909     │
└────────────────────────────────────────────┘
```

- 比例条：圆角 6，按 涨停/上涨/下跌/跌停 家数占比分段填色（涨停/上涨=`rise` 系，下跌/跌停=`fall` 系，涨停/跌停加深一档区分）。
- 下方 4 个数字**纯文本行**（非卡），末位「涨跌差 +909」加 `ink-1` 加粗——这是原 4 卡丢掉的最有价值的关系。
- **状态**：`loading`（脉冲条）/ 实时（比例条带 200ms 过渡）。

### D. 领涨板块（分层榜单，非 5 等卡）

```
┌─ SectionLabel：领涨板块 · 涨幅 + 主力净额 + 涨跌家数 ─┐
│ ╭─ #1 特色玻璃面板（浮起）─────────────────────╮ │
│ │ 半导体     ▲ +3.82%       主力 +28.6 亿       │ │
│ │ ── 成分广度 spark（涨/跌家数比）──    [问 AI]  │ │
│ ╰────────────────────────────────────────────╯ │
│ ▏#2 计算机     ▲ +2.91%   主力 +14.2 亿          │ ← 等级条长度编码名次
│ ▏#3 汽车       ▲ +2.04%   主力 +9.8 亿           │
│ ▏#4 医药       ▲ +1.77%   主力 +6.1 亿           │
│ ▏#5 军工       ▲ +1.32%   主力 +3.3 亿           │
└────────────────────────────────────────────────┘
```

- #1：玻璃浮起面板，名 `title 16` + 涨幅 chip + 主力净额 + 成分广度 spark（SVG，涨家数/跌家数比）+ 小「问 AI」桥。
- #2–5：**排名行**，左侧 2px 等级条长度按名次递减（`#2` 满宽 → `#5` 60%），发丝 `borderTop` 分隔，**不用卡片容器**。名次本身成为视觉层级。
- 每行可点 →「半导体板块今天为什么领涨？」。
- **状态**：`loading`（骨架）/ 实时。

### E. 资金视角（玻璃 slim strip）

- 一条玻璃 slim strip，3 项：北向资金净流入 / 主力净流入(全市场) / 成交额相对 20 日均值。每项 = 标签 `meta` + 数字 `body` + 涨跌色 + 一行极简相对位说明。
- 目的：把「钱从哪来」压成一行，不另开一屏。

### F. 异动聚焦（连板高度 / 涨停封单，复用排名语言）

- 与 D 同构：#1 连板高度（如「某某 7 连板 · 封单 12.3 亿」玻璃浮起）+ #2–N 排名行。
- 仅在数据可得时挂（东财涨停池 `lbc` 连板数 / `fund` 封单），克制默认不展开过长。
- **合规**：只陈述连板高度与封单额（事实），不暗示「该追」。

### G. 解释条（合规必须保留）

- 发丝 `borderTop` + `ink-3` `label 11`：「领涨不代表适合追入。板块页会继续拆解涨停集中度和连板高度，帮助区分普涨、局部题材与情绪拥挤。」
- 复用现有 `ExplanationCard` 文案。

## 5. 首页 AI / 市场 双模设计（你提到的未来因素）

> 首页欢迎区未来会有「AI / 市场」切换（doc 15 的欢迎区将升级为双模）。市场页必须能被「市场模式」直接复用，而不是另写一屏。

### 5.1 抽出 `MarketSnapshot` 组件

把 **A（情绪 Hero）+ B（三大指数主从）+ C（市场宽度条）** 抽成独立组件 `MarketSnapshot(theme, overview, onAskAi)`，满足：

- 自包含：不依赖市场页滚动容器，可独立嵌入首页「市场」模式。
- 桥接 AI：组件内每个区块的「问 AI」回调统一收口到 `onAskAi(prompt)`。
- 视觉一致：用同一套 `marketGlass` / 氛围底 / 比例条，首页市场模式与市场页是**同一套语言**。

### 5.2 首页双模结构

```
首页（ChatPage 欢迎区升级）
├─ 顶栏 / 灵动岛：分段控件 [ AI | 市场 ]（品牌色滑动指示器，复用详情页 Tab 曲线）
├─ AI 模式（默认）：现有欢迎区（问候 + 能力 pill + 示例问题 + 信任条）— doc 15 方案 C
└─ 市场模式：渲染 MarketSnapshot（A+B+C 浓缩）
   · 下方继续挂 D（领涨榜单）前 3 名，点击「查看完整市场」→ 打开 MarketPage
   · 顶部「问 AI 今天市场怎么看？」常驻，切换市场模式不丢失 AI
```

### 5.3 为什么这样设计

- 切换「市场」≠ 离开 AI。市场模式只是把「你能问什么」从「行情/术语/财报」重帧为「今天市场/板块/异动」——AI 入口反而更聚焦。
- `MarketSnapshot` 单一真源，避免首页与市场页两套市场 UI 漂移（divergence 风险）。
- 详情页、市场页、首页市场模式三处共用 `marketGlass` / 比例条 / 排名语言 → 全 App 视觉一致。

## 6. 微交互签名（复用 doc 19 四个 + 市场专属）

1. **数字翻牌器 Ticker**：上证价 / 情绪分更新时翻牌（320ms spring）。仅焦点数字。
2. **实时脉冲点**：情绪 Hero 信源时间前常驻（1200ms 线性循环）。
3. **顶栏进度条**：钉顶栏底边，随滚动 0→100%（与 section 进度同步）。
4. **Section sticky 标签**：滚动跨区时，当前区名 + 2px 品牌色进度条（沿用详情页）。
5. **市场专属 · 氛围底视差**：滚动时氛围底 `translateY(0.4×)`，制造深度（非装饰，是层次的一部分）。
6. **市场专属 · 排名行轻反馈**：点击排名行，左侧等级条 200ms 品牌色脉冲一次（确认可点）。

> 所有动效 `prefers-reduced-motion` 降级：spring→ease-out、时长减半、脉冲/视差停。

## 7. 合规护城河（不做的事）

- ❌ 不新增信息维度（E/F 用既有东财字段，只是重排）。
- ❌ 不做「推荐/目标价/评级/买卖建议」（中证协 2026-06 高风险）。
- ❌ 不用红绿承载品牌；品牌只用深蓝。
- ❌ 不堆同质卡片（A 不用白卡、D 不用 5 等卡、C 不用 4 tile——这是本次重构的核心）。
- ❌ 不破坏「意图与数据分离」（ADR-11）与现有对话流。
- ✅ 解释条（G）、信源时间戳、AI 署名等合规文案**必须保留**。
- ✅ 引导语只用可陈述事实的问法（为什么/多少/对比什么），不出现「怎么选/该不该买」。

## 11. 验收标准

- [ ] 市场页**没有任何**「5 张等高同构卡」或「tile 方阵」；层次来自 z 轴玻璃深度，非盒子数量
- [ ] 上证指数作为主卡浮起，深证/创业板衬其后，明显主次
- [ ] 市场宽度是**一条比例条 + 纯文本数字**，不是 4 张 tile
- [ ] 领涨板块 #1 浮起玻璃面板，#2–5 用排名行（等级条编码名次），非 5 等卡
- [ ] 配色严格沿用 doc 19 权威 token；深蓝只出现在 App/AI 元素
- [ ] 浅色 / 深色双主题下玻璃面板文字对比度均达标
- [ ] 抽出 `MarketSnapshot`，首页「市场」模式可复用，视觉一致
- [ ] 每个区块「问 AI」桥可达，切换市场模式不丢失 AI
- [ ] 解释条 / 信源 / AI 署名等合规文案保留
- [ ] `prefers-reduced-motion` 下降级：视差停、脉冲停、入场直接显
- [ ] 动效仅 `transform`/`opacity`；滚动 60fps（Kuikly profiler）
- [ ] 所有颜色 / 字号 / 间距取自 `StockChatTheme` 令牌，无硬编码

## 12. 一句话总结

**用「玻璃层叠（z 轴深度 + 负边距重叠 + 极轻漫射）+ 主从数字 + 比例条/排名条数据可视化」替换「白卡 + tile 方阵 + 5 等卡」，把市场页从「又一张列表页」升级为「有层次、安静可控的市场概览舱」；不新增信息维度、不破「克制=护城河」，并抽出 `MarketSnapshot` 让首页「市场」模式与未来 AI/市场 双模直接复用同一套语言。**

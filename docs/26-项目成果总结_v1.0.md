## 四、遇到的阻碍：动效静默失效（核心难点）

Kuikly 声明式动画大量"冻结"（attr 不重跑 / 动画不播放），经系统诊断沉淀出 **R1–R5 规则**（见 AGENTS.md）：

| 规则 | 内容                                                                     | 典型案例                                                                  |
| -- | ---------------------------------------------------------------------- | --------------------------------------------------------------------- |
| R1 | observable 只能在 `attr/event/vif/vfor/vbind` 内读取才建立响应依赖；builder 闭包只读初始快照 | StockDetailPage 8 处系统性违规（TickerText、AttributionBlock 等），全部 lambda 化修复 |
| R2 | `animate()` 绑定 attr 内最后读取的 observable key，必须把驱动读取放在最后                  | 对比 lobby 四条件短路求值导致 driver 漂移、淡出丢失                                     |
| R3 | 每个 driver key 只注册一次动画；不同时间线用互斥分支或父子视图                                  | 灵动岛多形态动画拆分                                                            |
| R4 | vif/vbind 新挂载视图首帧不动画，需两帧 `mounted→presented` 状态翻转                      | CardSheet / 欢迎卡入场                                                     |
| R5 | 动画注册滞后一个变更周期；pre-state 注册 `linear(0)` 会被下次 flip 消费，入场退化为瞬移             | StockDetailPage 入场、snap 复位长尾隐患                                        |

- 已沉淀用户级技能 `kuikly-reactive-animation-audit`，完成全库 54 处 `animate()` 审计。
- 其他踩坑：stale lambda 快照（Boolean 须传 `() -> Boolean`）、BoxShadow 必须挂带 `size()` 的最外层 View、pan 事件必须用 pageX（自身 transform 会抵消 local x）。

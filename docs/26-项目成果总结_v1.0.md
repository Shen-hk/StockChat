# StockChat（股问）项目成果总结

## 一、功能

### 1. 跨端工程

- Kuikly / KMP，Android + H5 共用 commonMain；iOS / OHOS 壳就位。

### 2. AI 聊天闭环

- DeepSeek 真 SSE 流式输出 + 多轮上下文 + 停止/重试 + 会话持久化。
- 应用内 API 配置页 + 连接测试，Key 不进源码/APK。

### 3. 行情数据

- 腾讯行情三件套：快照 / 分时 / 日周月 K。
- 统一 QuoteRepository + TTL 缓存 + online/cache/offline 三数据模式。

### 4. 卡片体系 + 协议混排

- 8 类卡片模型 + CardRegistry 单一分发。
- FULL / COMPACT / MINI 三密度矩阵。
- 渐进披露：手风琴、资讯 Sheet、归因下钻、对比双列、Insight 嵌套深挖。

### 5. 详情页

- 分时 / 日周月 K 蜡烛图 + MA5/10/20。
- 指标区、AI 解读区、归因与资讯分区。

### 6. 新增模块

- 自选股、术语表（共用 entity 基础设施）。

## 二、动效

- **灵动岛**：三态形变、拖拽跟手、收起时按钮/文字按收缩进度揉合滑入。
- **抽屉开合**：跟手横滑 + 归位震动。
- **欢迎页**：示例卡阶梯入场 + 主题句打字机轮播。
- **其他**：输入框渐变描边 20fps 流动、实体长按预览条滑入/淡出。

## 三、交互

- **实体承接**：单击进详情 + 长按预览（MINI 行情条）。
- **输入增强**：`@标的` 联想 + `/` 指令候选 + 多行自适应 TextArea。
- **手势协调**：左缘手势条 + Sheet 三档拖动 + 死区防误触。

## 四、遇到的阻碍：动效静默失效

Kuikly 声明式动画大量"冻结"，经诊断沉淀出 **R1–R5 规则**（见 AGENTS.md）：

| 规则 | 内容 | 典型案例 |
| -- | -- | -- |
| R1 | observable 只能在 `attr/event/vif/vfor/vbind` 内读取才建立响应依赖；builder 闭包只读初始快照 | StockDetailPage 8 处违规，全部 lambda 化修复 |
| R2 | `animate()` 绑定 attr 内最后读取的 observable key，必须放最后 | 对比 lobby driver 漂移、淡出丢失 |
| R3 | 每个 driver key 只注册一次动画；不同时间线用互斥分支 | 灵动岛多形态动画拆分 |
| R4 | vif/vbind 新挂载首帧不动画，需两帧 `mounted→presented` 翻转 | CardSheet / 欢迎卡入场 |
| R5 | 动画注册滞后一个周期；pre-state 的 `linear(0)` 会被消费，入场瞬移 | StockDetailPage 入场修复 |

- 已沉淀审计技能，全库 54 处 `animate()` 盘点完毕。
- 其他踩坑：stale lambda 快照、BoxShadow 须挂最外层 View、pan 须用 pageX。

## 五、后续计划

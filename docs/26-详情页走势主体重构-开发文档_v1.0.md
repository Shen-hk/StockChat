## 0. 一句话决策记录

详情页从「Hero + 指标卡 + 小走势图并列」改为：**整页氛围色由涨跌驱动 → 自绘分时升为页面第一实体（约 3.2 倍篇幅）→ 原「行情数据」8 格卡降级为走势卡玻璃蒙层 + 卡下次级行**。资金流/财务/股东/龙虎榜/公告/AI 解读/归因等既有卡片**顺序不变，整体尾随走势实体之下**。

非目标：不改 K 线（日/周/月）、不改数据源架构（ADR-6/11）、不新增页面、不做买卖建议表述。

### 0.1 实施实测记录（2026-09-07 真机 600519）

## 3. 氛围色（改动点 ①）

### 3.1 规则

- 驱动：`quote.change` 符号 → `toneColor()/toneSoftColor()`。**涨=rise 系、跌=fall 系、平盘/停牌/非交易时段=flat 火且整页降饱和 55%**（沿用 doc 21 §5 时段态约定）。
- 只用 doc 19 token（riseSoft `#FCEDED` / fallSoft `#E9F4EE` / page `#F5F6F8`），**不新增饱和色**。
- 布局随 quote 刷新切换：Scroller 底层颜色走 `vbind({ page.quote })` 重建（MarketPage 同款范式）。

### 3.2 实现（Kuikly 无渐变 attr，两层结构）

```
Scroller 底（kt:164 落点改为透明）
└─ AtmosphereBackdrop（新增组件，absolutePosition 铺满内容宽）
   ├─ wash 层：toneSoft 纯色块，高 ≈ 0.58 × 首屏可视高
   └─ 过渡层：Canvas 纵向 LinearGradient（toneSoft→page）
```

- **首选** Canvas LinearGradient（Android Paint shader 支持；H5 端验证，不支持则降级）。
- **降级方案**（shader 不可用时）：wash 纯色块 + 其下叠 3 条 alpha 阶梯的 page 色横条（0.35/0.65/1.0），条高 24f，视觉近似渐变。两条路径都写在 `AtmosphereBackdrop` 内部，调用方无感。
- **光晕**：走势卡后置 Canvas，10 层同心圆 alpha 从 0.10 线性衰减到 0（toneColor 为基色），直径 ≈ 340f，中心对齐卡顶。纯 Canvas 实现，跨端无分歧。

### 3.3 禁止

- 禁止给光晕/wash 引入 rise/fall 实色大面（soft token only）；禁止平盘态仍显示涨跌氛围。

## 4. 自绘分时主体 `DetailTimelineChart`（改动点 ②，新文件）

### 4.1 技术选型：**弃 ChartKit（本页），Canvas 自绘**

`KuiklyTimelineChart`（KuiklyChartKit AreaChart+BarChart）无法表达本页必需的：每分钟红绿量能、均价第二线（AreaChart 双 series 会双双填底）、昨收虚线基准、高低锚点、对称涨跌幅双轴标注。本页是「第一实体」，控制力优先；**ChartKit 保留给卡片小图与 CardGallery，本文件不动**。自绘先例：`AppChrome.kt` 灵动岛简笔分时（Canvas + TimeLineCalculator，kt:910 `islandSketchPoints`）。

新文件：`page/components/DetailTimelineChart.kt`（与页面同模块，internal）。

### 4.2 几何与坐标

容器宽 `w = 页宽 − 32(页边距) − 24(卡 padding)`，390dp 机型 ≈ 334f。参数（对照原型 cfg）：

| 参数 | 值 | 说明 |
|---|---|---|
| 总高 | 340f | 价格区 220f（y: 12→232）+ 量能区 60f（y: 246→306）+ 时间轴标注 20f |
| 左轴区 | 38f | 价格刻度（2 位小数，8.5sp，textTertiary） |
| 右轴区 | 40f | 涨跌幅刻度（对称：`±d%`、`±d/2%`、`0.00%`） |
| 对称半径 d | `max(|high−pc|, |low−pc|, |avg−pc|) × 1.08`，下限 `pc×0.1%` | 昨收恒居视觉中线 |
| x 映射 | `L + i/240 × plotW`，i∈[0,240] 固定 241 槽 | 盘中未走完的槽留空（生长态） |

几何计算扩展 `TimeLineCalculator`（`ChartCalculator.kt:15`）：新增 `calculateSymmetric(quotes, width, height, baseline, padRate)`，返回对称 range + 基线 y + 点位（现 `calculate` 不动，灵动岛继续用）。

### 4.3 视觉元素清单（z 序从底到顶）

1. **网格**：横 5 条（昨收 ±d、±d/2，昨收线不加网格）、竖 5 条（09:30/10:30/11:30·13:00/14:00/15:00），`divider` 色。
2. **昨收基准**：1f 虚线（dash 4/3），textTertiary，opacity .75。
3. **价格面积**：路径闭合到昨收基线，**上下双 clip**——基线上方 fill `toneColor.opacity(.16)→.02` 纵向渐变（无 shader 时纯 `.12` 单色），下方 fill 对侧语义色 `.10`。
4. **价格线**：1.7f，`toneColor`，圆角连接；**draw-on 入场**（§4.5）。
5. **均价线**：1.1f 虚线（dash 3/3），textSecondary，opacity .8；卡头 legend「价格/均价/昨收」。
6. **量能条**：每分钟一根，宽 `plotW/240×0.62`；**颜色按该分钟相对前一分钟涨跌**取 rise/fall/flat（首根对今开），opacity .62（flat .5）。
7. **高低锚点**：全天最高/最低点 2.6f 圆点 + 「高 1338.86」/「低 1295.60」8.5sp 标注，x 向内 clamp 26f 防出界。
8. **now 点（盘中）**：最后一点 2.8f 实心 + 外圈 1.8s 脉冲环（R4 两帧，§4.5）；收盘态不画。

### 4.4 十字光标 + 随值卡

- 手势：长按（与实体长按 Context Bar 同范式，`longPress` 事件 + 移动续跟）；实现遵守 `.workbuddy/memory/2026-09-03.md` 手势实测基线（CaptureRuleDirection / PanGestureParams）。
- 命中：x 反算最近槽位 i；竖虚线（12→306）+ 价格/均价两个空心点。
- 随值卡：玻璃小卡（`marketGlass` 材质 + 高光描边，复用 `hostGlassRenderer`），内容三行：`HH:MM · 量 N手` / 价格 + 相对昨收涨跌幅（语义色）/ `均价 x.xx`；左右 clamp 12f，近右缘翻到指针左侧。

### 4.5 动画（严格走 AGENTS.md R1–R5）

| 动效 | 参数 | 规则落点 |
|---|---|---|
| draw-on 入场 | progress 0→1，easeOut 420ms | **R4**：Canvas 挂载后 `setTimeout(0)` 翻 `mounted→presented`；draw 闭包内读 `progress()` observable 按 R1 建立依赖，progress 由 observable 计时驱动；**R5**：presented 态每个 cycle 注册同一动画，禁止注册 0 时长复位动画 |
| now 点脉冲 | 外圈 r 3.4→8、opacity .9→0，1.8s 循环 | 双帧 state 机同上；`reduceMotion` 时静态实心点 |
| quote 刷新生长 | timeline 追加点，曲线平滑延伸 | 数据驱动重建（`vbind({ page.quote })`），不做补间 |
| 降级 | `reduceMotion=true` | 全部退化为静态终帧 |

**安全阀**：入场动画链路必须有版本守卫兜底（参照 `ChatPage.scheduleWelcomeEntranceSafety`），任何 ref→setTimeout 断链不得停留在 opacity 0 / progress 0。

### 4.6 数据与均价口径

- `QuotePoint` 增加字段：`val amount: Double = 0.0`（该分钟成交额，元）。`Quote.timeline` 不变。
- `TencentProvider` 分时解析：`web.ifzq.gtimg.cn/appstock/app/minute/query` 返回 `HHMM 价 累计量(手) 累计额`，**逐分钟差分**量额后填充（2026-09-07 实测可用；date 参数不生效，勿再试）。
- 均价：`cumAmount / (cumVolume × 100)`，逐点累计。`amount` 全 0（Mock/旧缓存）时降级近似 `Σ(price×volume×100)`，**两种口径都不得标注为「真实均价」以外的话术**（UI 标签就叫「均价」）。
- 分时接口失败：走既有三级降级链（真实→缓存→Mock）；Mock 分时必须带 `isMock` 标记，页内由 `dataModeLabel` 徽标呈现（现状已支持，kt:236）。

### 4.7 单测（新增 `DetailTimelineChartTest`）

固化 2026-09-07 茅台实测基线：① 241 槽映射与盘中截断；② 对称 range 与基线 y；③ 均价累计（真实 amount 口径 vs 近似口径偏差 < 0.5%）；④ 量能红绿判定（首根对今开）；⑤ 高低锚点 index；⑥ `amount=0` 降级路径。

## 5.5 新闻弹幕带 `NewsTape`（新增组件，2026-09-07 追加需求；**形态已定：单条队列式**）

### 5.5.0 形态决策：单条队列，不做双车道灯带（2026-09-07 二次评审）

- **场景性质**：灯带/双车道是「看视频」场景的产物（注意力在画面上，弹幕是伴奏）；详情页是「读」的场景（注意力在走势上，新闻是背景上下文）。双车道持续漂移 = 用户既不读、又一直被余光骚扰的最差存在方式；单条「一条飘完 → 1.5s 间隔 → 下一条」想看能读到、不想看几乎无感。
- **价值密度**：个股新闻低频（数条/日）且混有弱相关榜单，双车道高吞吐播低价值内容；单条队列天然逼出**筛选**——只挑相关度高的进队列（≤12 条，按 `Art_Code` 去重）。
- **克制铁律同源**：它是注脚不是第二主角，单条式的视觉预算才是「注脚」的量级。
- **双车道灯带的正确归宿**：市场页顶部多标的快讯 ticker（如后续立项，另立组件）。
- 工程收益：单 driver 单动画注册，节流/降级/空态都更简单。

### 5.5.1 位置决策：Hero 与走势主卡之间，**不叠在走势上**

- **LDRS-L（遮蔽测试）**：走势是页面唯一主实体，漂移文字叠图即破坏「一眼只剩走势」的判定；放卡上沿之外则既保有「正在发生」的临场感，又不与十字光标/高低锚点抢注意力。
- **手势冲突**：叠图弹幕必然压住十字光标的手势捕获带；独立条带零冲突。
- **信息分层**：弹幕 = 即时快讯流（滚动过境、不求读完）；全量新闻/公告仍归下屏「公告与研报」区（存档层）。两层语义分开，互不稀释。
- **情绪一致**：紧贴价格区（氛围色区），与涨跌氛围同屏呼吸；但弹幕条本身**中性玻璃材质，不染涨跌色**。

### 5.5.2 规格

- 容器：全宽（页边距 16f）、**高 34f 单车道**、`marketGlass` + blur14、radius 11f，左右 28f 渐隐遮罩（「过境」语义）。
- 队列节拍：一条从右缘进场，匀速 ≈55dp/s 完整飘出左缘（**时长随标题长度自适应**，长标题自动放慢）→ 停 1.5s → 下一条；同屏**最多 1 条**。
- 内容：`标题(11sp ink) + 来源 · MM-dd HH:mm(9.5sp ink3)`；**不做涨跌语义染色**，不加「问 AI」按钮（数据流不是 AI 触点，不计入三铁律配额）。
- 交互：**按住/悬停暂停**（长按手势捕获，与 §4.4 光标同范式；松开继续，不丢进度）；点击弹幕项 → 玻璃摘要卡（复用 `CardSheet.kt` 底部卡范式）：标题 / 来源 / 时间 / 接口 summary 字段 / 原文链接（H5 端 `openUrl`，Android 端先用系统浏览器）。**不做站内正文渲染**（合规与成本双控）。
- 数据源：东财个股资讯 `https://np-listapi.eastmoney.com/comm/web/getListInfo?cfh=1&client=web&mTypeAndCode={1.600519}&type=1&pageSize=20&pageIndex=1`（2026-09-07 实测可用；字段 `Art_Title / Art_ShowTime / Author / Art_Url`，UTF-8；**需带 UA + Referer，遵守既有 ≥200ms 请求间隔**）。腾讯个股资讯 `getNewsByCode` 已 404（ADR-6 结论维持）。接入三级降级链。
- 降级与空态：接口失败走缓存（保留上一批标题）；**列表为空时整条隐藏，不显示占位**（克制铁律：无内容的氛围件不做）。

### 5.5.3 Kuikly 实现注意（动画红线）

- 单条平移：**单 driver 单注册**（R3）。commonMain 无时间源（实测基线），用「observable offset driver + linear animate」单周期播放（右缘 → −条宽），onEnd/timeout 链接「1.5s 间隔 → 下一条」，**换值触发**（R5：同值写入不通知，循环 reset 必须变值）。
- 队列索引是唯一状态；标题变化（下拉刷新）走 `vbind` 重建，不热改动画参数。
- `reduceMotion`：退化为静态单行（显示最新一条 + 可点击），无平移。
- 入场：随走势卡 R4 两帧淡入即可，不单独做入场动效。

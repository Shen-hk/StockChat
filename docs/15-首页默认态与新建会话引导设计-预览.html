1现状诊断：现有欢迎区有什么问题

问题说明
没有背景层纯 page 底色 + 居中三行文字，首屏视觉重量几乎为零——这正是"太简洁"的第一观感来源。
图标是 emoji用 📊 📖 ⚖ 和 Unicode 字符 ↗ 拼图标，跨端字形不一致（尤其 Android / H5），且项目已有 LineIcons.kt 线性图标库却未使用。
介绍词太薄只有一句 slogan，没告诉新用户"你能拿它干什么"，能力边界不明。
信任资产没亮出来ADR-11「意图与数据分离」保证行情零幻觉，这是对抗"AI 给我 2024 年资料"这一最大抱怨的武器，却只存在于架构文档里，用户在首屏看不到。
⚠ 合规风险文案第三条示例「茅台和五粮液怎么选？」——"怎么选"是选股建议的边缘，与 Non-goals「不做荐股机」直接冲突。必须替换为纯事实对比式提问。

2介绍词文案（三方案共用）

问候语下午好— 按时段变化：早上好 06-11 / 中午好 11-13 / 下午好 13-18 / 晚上好 18-06
主标题你好，我是股问
Slogan做股民的解释器，不做荐股机
能力说明解释涨跌 · 讲清术语 · 读懂财报— 三个 pill，告诉新用户能力边界
信任条行情来自交易所实时数据 · 每条结论都标了出处和时间— 一句话把 ADR-11 的架构优势翻译成用户能懂的话
为什么信任条必须加：调研里最刺痛的一条用户原话是「AI 一直给我过去的消息，问完一看股价根本不对，再问它，说看的是 2024 年的资料」。 股问的架构天然免疫这个问题（LLM 只出意图，数字由端侧 Provider 填真实数据），但用户不读架构文档。把这句话放在首屏，是成本最低、差异化最强的信任建设。

3示例问题：重分类 + 去合规风险

分类问法说明
解释异动贵州茅台今天为什么跌？对应最高频需求（异动提醒 62.4%），排第一
讲清术语MACD 金叉是什么意思？对应"散户投资知识 58.8 分"这一最大空白
读懂财报用三句话讲下贵州茅台的中报新增。财报季是月活增长主因，且"财报看不懂"是 49% 散户的痛点
事实对比对比茅台和五粮液的营收与净利润替换原「怎么选」。只陈述事实，不做选择建议——不碰中证协分级表里"高风险"的个股推荐/估值
文案铁律：欢迎区里任何一条引导，都不能出现"怎么选""该不该买""值得买吗""推荐"。 全部改成可陈述事实的问法（是多少 / 为什么 / 什么意思 / 对比什么）。

区块首次 / 空会话新建会话（老用户）

判断依据：欢迎页的价值是"降低第一次开口的门槛"，不是"每次都重新介绍自己"。 老用户点"新会话"是来找入口的，不是来看介绍的。精简版把首屏高度压掉约 40%，直接看到示例问题。

5落地要点（移植到 Kuikly 时）

项说明
背景实现Kuikly 无 radial-gradient 原生能力。方案：① 背景层用 Blur + 纯色 View 叠加模拟光晕（复用 glass/GlassRenderer 的三级降级）；② 或预置一张极轻的渐变位图。建议先按 ①，降级时退回纯 page 底色。
玻璃卡直接复用 GlassContainer，与顶栏岛、输入栏胶囊同一材质系统，保持一致。
图标全部换成 LineIcons.kt 线性图标（需新增：trend-down / book / file-text / columns / shield-check）。不要再用 emoji。
Token字号走 theme.type（display 38 / h1 20 / title 16 / body 14 / sm 13 / label 11 / meta 10），间距走 theme.spacing，颜色只取 StockChatTheme 已有 token，不新增硬编码色值。
打字机动效仅方案 C 需要。Kuikly 可用定时递进子串实现；若工期紧可先做静态文案，动效留到打磨阶段。
问候语时段复用 QuoteClock 的当前时间取值逻辑，按本地小时判断。
示例轮换在 KeyValueStorage 记一个"已问分类"集合，新建会话时优先取未覆盖分类。
色值取自 StockChatTheme.Light / Dark，与项目主题令牌一致。原型仅用于方案确认，确认后按第 5 节要点移植到 ChatScaffolding.kt 的 WelcomeSection。

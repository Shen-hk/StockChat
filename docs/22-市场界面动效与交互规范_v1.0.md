## 0. 行情动效的第一性原则

行情页的动效不是「让它动起来」，是**用运动编码信息**。屏幕上任何一处运动都必须回答「什么变了、变了多少、要不要紧」。不承担这三个问题的运动，一律删除。

四条硬约束：

1. **禁止闪烁地狱。** 逐笔数据若逐条重绘，界面会不可读。核心指标用「变动触发式」刷新，成交量类用 **500ms 节流合并渲染**，图表用「动画补间」而非跳变。
2. **布局绝不因数字变化而抖动。** 全部数字使用等宽数字（`tabular-nums` / Kuikly 侧固定字宽 + 右对齐 + 预留最大位数宽度）。
3. **闪烁频率上限。** 同一元素 tick flash 触发间隔 <200ms 时合并；全屏同时闪烁元素 >6 个时降级为「仅主指数闪」。
4. **动效可完全关闭。** 系统「减少动态效果」开启时，全部位移/缩放/脉冲降级为**瞬时状态切换**，仅保留颜色变化。午休与休市时段动效全局静止。

## 1. 视觉显著性梯度（异常预警的核心机制）

这是全页最重要的一条交互规则：**用视觉强度编码异常程度**，而不是所有数字长一个样。

| 级别 | 触发条件 | 视觉处理 | 动效 |
|---|---|---|---|
| L0 正常 | 涨跌幅 ≤3% | 常规字重 500，语义色 | 仅 tick flash |
| L1 关注 | 涨跌幅 >3%，或量能偏离 5 日均值 >10% | 字重 600 + `riseSoft/fallSoft` 背景色块（圆角 4，横向内边距 4） | tick flash + 背景色块 240ms 淡入 |
| L2 显著 | 涨跌停 / 炸板 / 秒板 / 封板率跌破 80% / 最高板下降 ≥2 板 | 字重 700 + 实心语义色底 + 白字 | **脉冲动画**：scale 1→1.04→1，1200ms，`ease-in-out`，重复 2 次后停止 |
| L3 系统级 | 单一板块涨停数环比骤降 >70%（主线终结）/ 指数跌破关键关口 | L2 视觉 + 触发一条 AI 内联归因（doc 21 §4 铁律 1） | 脉冲 + 归因行 320ms 展开 |

> L2 的声音提示：A 股场景默认**关闭**，仅在用户显式开启「异动播报」后启用。我们不是盯盘工具，不主动制造焦虑。

## 2. 数字动效规格

### 2.1 tick flash（价格/涨跌幅变动）

| 参数 | 值 |
|---|---|
| 触发 | 数值发生变化（变动触发式，非定时） |
| 上涨 | 背景 `riseSoft` #FCEDED，文字 `rise` #D92E2E |
| 下跌 | 背景 `fallSoft` #E9F4EE，文字 `fall` #0C7A45 |
| 时长 | 淡入 80ms → 保持 220ms → 淡出 300ms（**总 600ms 自动复位**） |
| 曲线 | 淡入 `ease-out`，淡出 `ease-in` |
| 合并 | 600ms 内再次变动 → 重置计时，不叠加图层 |
| 圆角/内边距 | 4 / 横向 4，绝不改变元素占位尺寸 |

### 2.2 数字过渡（大数字，如指数点位、成交额）

- 使用**弹簧过渡**而非线性插值：`stiffness 170, damping 26`（近似 spring(0.5, 0.8)），感知时长约 400–500ms
- 仅对**位数不变**的变化做插值；位数变化（如 9999→10000）直接切换避免视觉跳格
- 涨跌幅百分比**不做插值**，直接切换 + tick flash（百分比插值会读出错误中间值，属误导）

### 2.3 大数字入场（Hero 指数点位）

- 首次渲染：透明度 0→1（240ms）+ Y 轴 8px 上移，`cubic-bezier(.22,.61,.36,1)`
- 数字从 `0.94` scale 到 `1`，与透明度同步
- **不做逐位翻滚（odometer）**：金融数字翻滚会让用户误读中间值，且与「稳」的气质冲突

## 3. 图表动效

### 3.1 分时图 draw-on

- path 描边动画：`stroke-dasharray` 从 0 到全长，**680ms**，`ease-out`
- 面积渐变填充在描边完成 60% 时开始淡入（180ms），避免填充跑在线条前面
- 均价线（黄线）延迟 120ms 后以同样方式绘制，形成主次
- 实时追加点：新点直接接续，**不重绘全 path**；最新点带一个 1.5s 循环的呼吸光点（仅盘中时段）

### 3.2 K 线 / 柱状图

- 柱体从基线向上生长：**320ms**，`ease-out`，按索引 stagger **8ms**（40 根柱总计 320ms 内完成，不拖沓）
- 数据更新用**动画补间**：旧值→新值 240ms，禁止跳变
- 缩放/平移手势：跟手无延迟，惯性衰减 `deceleration 0.92`

### 3.3 市场宽度比例条

- 涨/跌两段从中心分界线向两侧生长：**520ms**，`cubic-bezier(.22,.61,.36,1)`
- 两段**同时**生长（不 stagger），因为它们是同一个事实的两面
- 数字（1541 / 3901）在条生长到 70% 时淡入
- 分界线位置变化时用 320ms 补间，让「多空天平倾斜」被看见

## 4. 手势与转场

### 4.1 下拉刷新（行情页专属形态）

普通 App 下拉转圈在行情页是浪费——下拉过程本身应该给信息。

| 阶段 | 行为 |
|---|---|
| 下拉 0–48px | 顶部露出「上次更新 15:00:03」时间戳，随位移淡入 |
| 48–72px | 文案切「松手刷新」，指示器由**三大指数微型 sparkline** 组成，随下拉逐段绘制 |
| 松手 | 回弹 `spring(stiffness 220, damping 24)`；请求期间 sparkline 做 1.2s 循环流光 |
| 完成 | 变动的数字统一触发 tick flash（**stagger 30ms 由上至下**），顶部显示「已更新 · 3 项变动」，1.6s 后淡出 |
| 失败 | 顶部条变 `surfaceMuted`，文案「更新失败 · 显示 15:00 缓存数据」，**保留旧数据不清空** |

### 4.2 区块下钻（第一级 → 第二级）

- 采用**共享元素转场**：被点击区块的标题与主数字保持位置连续，其余内容淡出
- 时长 **380ms**，`cubic-bezier(.32,.72,0,1)`（iOS 风格，前段快后段稳）
- 返回时反向播放 320ms（返回比进入快，符合预期）
- 手势：右滑返回全程跟手，松手阈值 30% 宽度

### 4.3 长按快速看板（peek）

复用项目既有的 Context Bar 范式：

- 长按 **380ms** 触发（与 doc 07 手势规范一致），触发瞬间 haptic light
- 元素 scale 到 0.97 + 上浮出玻璃浮层（阴影 y8 blur24 opacity .10）
- 浮层内容：该指数/板块的分时缩略 + 3 个关键数 + 一行口径说明
- 松手收起 240ms；上滑至浮层内可继续交互（转为常驻卡）

### 4.4 顶栏滚动紧凑态（即"吸顶指数条"，非独立浮层）

> 改前：独立 44px 浮层钉在顶部 → 与页面「市场」标题栏（AppTopBar）**必然重叠**，或变成第二层 sticky 吃掉 44px 且双 sticky 抖动。已废除独立浮层，并入 AppTopBar 自身滚动态。复用详情页 `doc 19 §H.1`「滚动 >60px 切紧凑态」同一范式，顶部始终是**一个**栏。

- 常态顶栏：左返回 · 中「市场」+ 副标题「数字之后，解释今天发生了什么」· 右 热点 / 日历
- 滚动超过 **Hero 底边 - 56px** 时，`AppTopBar` 切紧凑态：标题与副标题 `opacity 0→0`（收起），**center 原位替换为 三大指数 mini 条**（上证 / 深证 / 创业板 + 涨跌幅，等宽数字）
- 切换用**交叉淡入 + 4px 位移**，200ms，绝不用高度动画（会导致回流抖动）；顶栏整体高度不变，不新增浮层
- 与标题不冲突：紧凑态占用同一顶栏的 center 区，标题收起让位，二者**互斥同区、不重叠**，不会出现第二层 sticky
- mini 条内数字继续实时 tick flash，但**降一级显著性**（L2 降为 L1，避免顶部持续脉冲干扰阅读）

### 4.5 板块热力图交互

- 进入：格子按「涨跌幅绝对值降序」stagger **14ms** 淡入 + scale 0.96→1
- 点击格子：FLIP 展开为该板块详情（格子原位放大到卡片），**420ms**，`cubic-bezier(.32,.72,0,1)`
- 长按格子：peek 出板块内涨停股名单
- 色阶：**仅用明度与饱和度编码强度**，不引入新色相（doc 19 token 锁定）

### 4.6 连板梯队交互

- 入场：从**首板层向高板层**逐层升起（与「梯队高度」的空间隐喻一致），层间 stagger 60ms，每层 Y 轴 12px 上移 + 淡入，280ms
- 高度坍塌时（今日最高板 < 昨日）：昨日高度用**虚线残影**标示在上方，残影 800ms 淡入，让「坍塌」可见
- 点击某一层展开该层股票列表：height 展开 320ms + 内容延迟 80ms 淡入

## 5. 加载与空态

### 5.1 骨架屏（不用通用灰块）

- 骨架形状必须**与真实内容同构**：指数带是 3 个圆角矩形 + 下方短条；宽度条是一条居中分界的浅色横条
- shimmer：135° 线性渐变扫过，**1.4s** 循环，透明度峰值 0.06（极轻，不抢注意力）
- 骨架 → 真实内容：交叉淡入 200ms，**位置零位移**（骨架尺寸必须精确等于真实内容尺寸）

### 5.2 渐进加载顺序（首屏 TTI 优化）

`时段条 → 指数带（缓存优先）→ Hero 定性 → 量能/宽度 → 情绪四维 → 梯队/板块 → 资金`
每段就绪即渲染，禁止等全部数据齐了再整页出现。三级降级链（真实→缓存→Mock）在每段独立生效，缓存数据显示时右上角带一个 `缓存 15:00` 灰色角标。

### 5.3 时段切换转场

跨越时段边界（如 11:30 进午休）时：
- 全局饱和度过渡到 55%，**900ms** `ease-in-out`（慢，因为这是「氛围」变化不是「事件」）
- 顶部时段条文案交叉淡入 240ms
- 所有循环动效（呼吸点、流光）在饱和度过渡完成后停止
- 反向（13:00 复盘）：饱和度恢复 600ms + 三大指数依次 tick flash（stagger 80ms），像「重新开机」

## 6. 暗色模式差异

| 项 | 浅色 | 暗色 |
|---|---|---|
| 涨 | #D92E2E | #FF7878（提亮，暗底上低亮度红几乎不可辨） |
| 跌 | #0C7A45 | #54D6A6 |
| tick flash 背景 | #FCEDED / #E9F4EE | #3A2022 / #15342C |
| 分时价格线 | 2px 实线 | 2px + **外发光**（blur 6，同色 opacity .35） |
| 图表网格线 | #E2E8F0 | #363638，且饱和度必须低于价格线 |
| 玻璃面板 | 白 82% + blur 20 | #1D1D1F 76% + blur 24 + 顶部 1px 白 8% 发丝边 |
| 脉冲动画峰值 | scale 1.04 | scale 1.03（暗底上运动感知更强，需削弱） |

## 7. 性能预算

| 指标 | 目标 |
|---|---|
| 首屏骨架出现 | <120ms |
| 缓存数据渲染 | <300ms |
| 实时数据到位 | <1.2s |
| 滚动帧率 | 稳定 60fps，掉帧率 <1% |
| 同屏并发动画 | ≤8 个（超出则按显著性降级） |
| 刷新节流 | 快照 3s/次（盘中）、成交量渲染合并 500ms、非可视区域暂停刷新 |
| 后台/切页 | 全部定时器暂停，回前台先补一次全量再恢复轮询 |

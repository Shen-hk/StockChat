# 详情页高级感改版方案 v1.0

> 适用页面：`StockDetailPage`（`shared/src/commonMain/kotlin/com/kuikly/stockchat/page/StockDetailPage.kt`，581 行）
> 目标：在不增加页面、不破坏"克制=护城河"铁律的前提下，把详情页从"标准数据汇总"升级为"为这只股票定制的高端分析舱"
> 范围：Hero · 行情数据 · 走势 · 关键指标 · 业务数据卡组 · AI 解读 · 涨跌归因 · 顶栏与底栏 · 全局动效语言
> 出品：2026-09-02

---

## 0. 设计三原则（写功能前先立住）

| 原则 | 落点 | 避免 |
|---|---|---|
| **秩序 > 花哨** | 数字一律等宽对齐；价格、涨幅、成交额三组关键数字同基线；section 之间用 24-32px 留白 | 花哨渐变、彩光、emoji 装饰 |
| **克制 = 护城河** | 每屏只一个"焦点数字"（当前价），其余全部降级为次级字号 | 堆砌模块、信息轰炸（moomoo 翻车） |
| **微交互 = 信任** | 所有按钮、tab、加载都有反馈；颜色变化带 200ms 过渡；重要操作（加自选）有确认微动效 | 静态点击、无反馈的状态切换 |

> 金融 App 高级感的第一性原理：**0.3 秒让用户觉得"这正规、我能掌控"**——这要求间距守恒、颜色克制、数字对得齐、动效有节奏，而不是堆视觉特效。

## 1. 现状诊断（基于截图与源码）

### 1.1 视觉现状
- **Hero**：价格 `1299.52` 直接红字巨号显示，无背景、无视觉锚点；右侧"加自选/详情"两个按钮挤在一行，与左侧"1299.52"信息密度不平衡
- **数据源徽标**：右上角"正在连接行情"是个静态胶囊，缺乏"实时"感知
- **行情指标网格**：4×2 整齐但"密"，所有数字同字号，没有主次
- **走势切换**：分时/日K/周K/月K 用 4 颗 tab 平铺，缺少滑动指示器；分时图为单线+虚线基准，信息密度低
- **关键指标**：仅 3 项（PE/PB/振幅），显得空洞
- **底栏**："回到对话"玻璃浮按钮宽度居中、偏粗，与 iOS 拇指区不匹配

### 1.2 关键痛点
1. **缺少"焦点"**：所有 section 同字号、同色、同间距 → 用户分不清该看哪里
2. **缺少"实时感"**：虽然是行情页，但"实时"几乎不可感知
3. **缺少"立体感"**：平面卡片堆叠，无 Z 轴层次，无玻璃态与底色的对比
4. **缺少"专属感"**：详情页像是通用模板，没有为"这只股票"定制
5. **缺少"动效叙事"**：滚动是死板的，进入是突变的，没有节奏

### 1.3 已经做得好的（不要丢）
- 顶栏玻璃态 AppTopBar（**保留并强化**）
- 行情数据用细分隔线网格（**保留**）
- 4-tab 走势切换（**保留交互，升级视觉**）
- SectionLabel 灰字小标题（**保留**）
- AI 解读顶部品牌色色条（**保留**）
- 涨跌归因分隔线列表（**保留**）

## 2. 高级感"配方"（2026 趋势 × 金融铁律）

### 2.1 借鉴的 6 个 2026 趋势
1. **液态玻璃 2.0（Liquid Glass）**：磨砂半透明 + 流动边缘 + 微妙色彩折射，金融/高端 App 常用 → 适合顶栏、底栏、卡组容器
2. **Bento Grid 2.0**：模块化非对称网格，Apple/Microsoft 已大规模使用 → 适合"行情数据 + 关键指标"重排
3. **3D 微质感**：细腻微立体、漫射阴影、Z 轴堆叠 → 适合 Hero 卡、走势图容器
4. **物理基础动效（Physics-based）**：自然惯性、弹簧曲线 `cubic-bezier(0.34, 1.56, 0.64, 1)` → 适合 tab 切换、加自选按钮
5. **动态变量排版（Kinetic Typography）**：数字翻牌器（ticker 风格）随报价更新 → 适合当前价、涨幅、成交量
6. **温度感主题（Adaptive Theme）**：白天冷白 + 蓝，夜晚暖炭 + 暖橙；不是简单的"反色" → 整套颜色 token 重做

### 2.2 坚守的 3 个金融铁律
1. **数字永远等宽（tabular-nums）**——所有金额、百分比、日期一律 `font-feature-settings: "tnum"`
2. **颜色克制**——每色都有含义：涨红、跌绿、灰中性、蓝品牌、暖橙强调；禁止同屏超过 3 种饱和色
3. **信息层级 ≤3 档**——主级（28-40px display）、次级（15-17px body）、三级（12-13px meta）

### 2.3 必须避免的反模式
- 全屏霓虹渐变（fintech 已翻车）
- 涨跌图标用箭头 + emoji（不够克制）
- 自动播放语音/震动（金融场景反人性）
- 任何"再不行动就晚了"的紧迫感文案（监管红线）

## 3. 详情页改版方案（按区块 A→H）

### A. Hero 区：液态玻璃焦点卡

**现状问题**：价格 1299.52 是孤立的红色大字，与下方行情数据没视觉关系
**改版方案**：

```
┌─────────────────────────────────────────┐
│ ╭─ 贵州茅台 600519.SH    • 实时  ╲×│  ← 顶栏（升级）
│                                         │
│ ╭─────────────────────────────────────╮ │
│ │  1299.52         ▲ +2.12  +0.16%  │ │  ← Hero 玻璃卡
│ │  实时价（翻牌器）   涨幅 chip       │ │     背景：淡红→淡白渐变
│ │                                     │ │     边框：品牌色 0.5px
│ │  数据源：腾讯证券  ·  16:14        │ │     阴影：极轻漫射
│ │                                     │ │
│ │  [+ 加自选]    [⏰ 提醒]            │ │  ← 玻璃双按钮
│ ╰─────────────────────────────────────╯ │
└─────────────────────────────────────────┘
```

**关键升级点**：
- **背景渐变**：`riseSoft(8%α)` → 透明 30%，涨时偏淡红、跌时偏淡绿、停盘时偏淡蓝（已是品牌色内变化，克制）
- **数字翻牌器（Ticker）**：当报价变化时（如 1299.50 → 1299.52），旧数字向下滚出、新数字向上滚入，时长 280ms，spring 曲线
- **涨幅 chip 加微光晕**：1px 内阴影 `inset 0 0 0 0.5px rise`，激活时再外加 6px 同色 8% 透明光晕
- **"实时"徽标**：脉冲点动画（核心 1.2s 缩放 + 外圈 1.2s 透明度淡出），让用户感知"真的在动"
- **加自选按钮**：点击瞬间 0.95x 收缩 → 1.05x 弹性回弹 → 文字"加自选 → 已自选 ✓" 280ms 过渡

**配色（新增）**：
- `heroSurface`：白底 + 1px 品牌色描边 + 极轻阴影
- `heroGradientRise`：rgba(229, 70, 70, 0.04) → rgba(255, 255, 255, 0)
- `heroGradientFall`：rgba(38, 161, 110, 0.04) → rgba(255, 255, 255, 0)
- `heroGradientFlat`：rgba(24, 95, 165, 0.04) → rgba(255, 255, 255, 0)

### B. 行情数据：分级 Bento 网格

**现状问题**：4×2 同字号，没有主次
**改版方案**：Bento Grid 2.0，主指标大、辅指标小

```
┌────────────────────────────────────────────┐
│ 行情数据                            实时报价│  ← sticky mini header
│                                             │
│ ╭─────────╮ ╭─────────╮ ╭─────────╮ ╭───────╮│
│ │ 今开     │ │ 最高     │ │ 最低     │ │ 昨收  ││  ← 第一行：价
│ │ 1297.99  │ │ 1305.00  │ │ 1286.00  │ │1297.40││
│ ╰─────────╯ ╰─────────╯ ╰─────────╯ ╰───────╯│
│ ╭───────────╮ ╭───────────╮ ╭───────────────╮│
│ │ 成交额     │ │ 换手率     │ │ 成交量        ││  ← 第二行：量
│ │ 30.03 亿   │ │ 0.19%     │ │ 2.3 万手      ││
│ ╰───────────╯ ╰───────────╯ ╰───────────────╯│
│ ╭──────────────────────────╮ ╭─────────────╮│
│ │ 总市值                    │ │ 振幅         ││  ← 第三行：值
│ │ 1.62 万亿                 │ │ 1.46%        ││
│ │ ▁▂▃▄▅▆▇ 7日市值         │ │              ││
│ ╰──────────────────────────╯ ╰─────────────╯│
└────────────────────────────────────────────┘
```

**关键升级点**：
- **3 行结构**：价（4格）→ 量（3格）→ 值（1大+1小），形成自然视觉重心
- **总市值卡嵌入 sparkline**：极简 SVG（7 日市值迷你折线），100×24px，颜色 `brand 40%α`
- **所有数字等宽对齐**：`font-variant-numeric: tabular-nums`
- **数字颜色规则**：高于昨收→rise，低于→fall，等于→textSecondary
- **小卡间分隔**：仍用 0.5px divider，**不**改用粗边（保持轻盈）

### C. 走势：可触摸的微立体图

**现状问题**：tab 平铺、走势图单线、无交互
**改版方案**：3 处升级

#### C.1 Tab 切换：滑动指示器

```
┌──────────────────────────────────────┐
│ ╭──────────────────────────────────╮ │
│ │  ╭──────╮                        │ │
│ │  │ 分时 │  日K   周K   月K       │ │  ← 高亮"分时"有滑块背景
│ │  ╰──────╯                        │ │
│ ╰──────────────────────────────────╯ │
│                                      │
│  [分时走势图]                        │
│                                      │
│  [分时成交量副图]  ← 新增             │
└──────────────────────────────────────┘
```

- 滑块用 **spring 曲线** 在 4 个 tab 之间滑动，280ms
- 点击的 tab 滑块会"略过"相邻 tab 再归位（轻微 overshoot 1.04x），物理感

#### C.2 走势图本体：触摸 + 副图

- **十字光标**：手指按住走势图时，显示竖线 + 当时价格气泡 + 时间气泡（玻璃态胶囊）
- **当前价横线**：右侧显示当前价标签（玻璃 chip），位置随价格实时变化
- **昨收基准线**：虚线 + 左侧标签"昨收 1297.40"
- **新增成交量副图**：分时模式下，K 线 70% 高度 + 成交量 30% 高度，成交量柱涨红跌绿
- **K线模式**：红涨绿跌（A股惯例），阳线实体 + 上下影线

#### C.3 周期手势

- **左右滑动切换周期**：在走势图区域水平滑动 30px+ 触发周期切换
- 切换时图表淡出（120ms）→ 加载骨架（脉冲条）→ 淡入（180ms）
- 总耗时 ≤ 320ms

### D. 关键指标：上下文卡片

**现状问题**：3 项指标平铺，缺乏上下文
**改版方案**：每项指标配"行业分位"

```
┌────────────────────────────────────────┐
│ 关键指标                                │
│                                         │
│ ╭─────────────╮ ╭─────────────╮        │
│ │ PE(TTM)      │ │ PB           │       │
│ │ 19.95        │ │ 6.42         │       │
│ │ ▔▔▔▔▔▔▁▁▁   │ │ ▁▔▔▁▁▁     │       │
│ │ 行业分位 28% │ │ 行业分位 45% │       │
│ ╰─────────────╯ ╰─────────────╯        │
│                                         │
│ 单一估值不构成结论，结合增长与质量看    │
└────────────────────────────────────────┘
```

**关键升级点**：
- 每项指标下加"行业分位"（数据可得：东财行业排名 → 百分位）
- 微型分布条：显示该指标在行业内的相对位置（从左到右：低→高）
- 提示语字号 12px、灰色 60% 透明度（克制）
- 数字本身仍是主要信息源（不要用过多"AI 解释"覆盖数据）

### E. 业务数据卡组：液态玻璃卡 + sticky 标题

**现状问题**：资金流、财务、股东等 6+ 个卡 section 串联，缺乏节奏
**改版方案**：

#### E.1 Section sticky 标题

- 滚动时 section 标签固定在 AppTopBar 下方（24px 高，玻璃态背景）
- 当前 section 名+一根 2px 品牌色进度条（左侧）
- 进入下一 section 时，旧标签淡出（160ms），新标签淡入（200ms）+ 进度条从 0 滑到 100%

#### E.2 卡片视觉升级

- 从 `surfaceMuted` 平卡 → **液态玻璃卡**：
  - 背景：`surfaceMuted` 95%α + 1px `divider`
  - 圆角：18px
  - 阴影：`0 2px 8px rgba(0,0,0,0.04)` 极轻漫射
  - 顶部保留品牌色色条（沿用 AI 解读已有的 4px 顶部色条）
- 卡组用 8px gap（之前 12-16px），密度增加但仍有呼吸

#### E.3 入场动效

- 滚动到视口时，整组卡片 staggered 入场：
  - 第 1 张：fade + translateY(8px → 0)，0ms 延迟
  - 第 2 张：同上，60ms 延迟
  - 第 3 张：同上，120ms 延迟
- 全部用 `cubic-bezier(0.16, 1, 0.3, 1)` 缓出曲线，280ms

### F. AI 解读：动效签名

**现状问题**：AI 解读已做得不错（顶部色条 + 圆点 + 灰字），但缺动效
**改版方案**：

- **首次进入时**：文字"打字机"逐字出现（30ms/字）
- **每条要点**用 **spring 滑入**（translateY(12px) + opacity 0 → 1，300ms）
- **重新生成按钮**（新增）：在 AI 解读卡底部"↻ 重新解读"小按钮，点击时旋转 360°（600ms）同时重新跑生成
- **底部署名**："AI 生成 · 仅供参考" 字号 11px，灰色 50%α

### G. 涨跌归因：可下钻

**现状问题**：归因是平铺列表，没有进一步动作
**改版方案**：

- 每条因子增加 **chevron** 提示可点击
- 点击展开 1 级详情：相关资讯 + 相关数据
- 收起时 chevron 旋转 90°（200ms）
- 整组因子用 0.5px divider 分隔

### H. 顶栏与底栏：可执行工具栏

**现状问题**：顶栏只有返回+标题；底栏只有一个"回到对话"按钮
**改版方案**：

#### H.1 顶栏升级

```
┌──────────────────────────────────────────┐
│  ← 返回   贵州茅台 600519.SH    ⊕ ⌘     │
│                                          │
│  ← 滚动后紧凑态：                        │
│  1299.52 +0.16%   ⊕ ⌘                  │
└──────────────────────────────────────────┘
```

- 常态：返回 + 标题 + 副标题（已是）
- **新增两枚玻璃图标按钮**：加自选（⊕/✓）、更多操作（⌘ 长按弹 sheet：分享、复制代码、添加到分组、设置提醒）
- **滚动 > 80px 切换为紧凑态**：标题缩小、加上"价格+涨幅"迷你信息条
- 状态切换用 spring 曲线 200ms

#### H.2 底栏升级

- 现状"回到对话"改为 **3 段式**：
  - **左**：胶囊"加自选/已自选"（玻璃）
  - **中**：胶囊"回到对话 ↗"（主操作，蓝品牌色）
  - **右**：胶囊"问 AI ↗"（玻璃，触发对话："为什么茅台今天涨了？"）
- 圆角 24px（与 iOS 工具栏一致），高度 46px
- 中段按钮为主色实底，左右两段为玻璃透明

## 4. 视觉系统升级（颜色 · 字体 · 动效）

### 4.1 颜色 Token 重做

| 层级 | Light | Dark | 用途 |
|---|---|---|---|
| `page` | #FAFAFA | #0E0E10 | 页面底色（**冷白**+**暖炭**，温度感） |
| `surface` | #FFFFFF | #1A1A1D | 卡片底色 |
| `surfaceMuted` | #F2F3F5 | #232327 | 二级卡底色 |
| `surfaceGlass` | rgba(255,255,255,0.7) + blur(20) | rgba(26,26,29,0.7) + blur(20) | 玻璃态 |
| `textPrimary` | #1A1A1F | #F5F5F7 | 主文字 |
| `textSecondary` | #5F5F66 | #B4B4BA | 次文字 |
| `textTertiary` | #9090A0 | #6E6E78 | 灰文字 |
| `rise` | #E54646 | #FF6B6B | 涨（**克制的鲜红**） |
| `fall` | #26A16E | #4ECB8B | 跌（**克制的墨绿**） |
| `flat` | #185FA5 | #5B9EFF | 停盘/品牌蓝 |
| `brand` | #185FA5 | #5B9EFF | 主品牌色 |
| `accent` | #C28B3B | #D9A85A | 强调暖橙（提示用） |

**新增渐变（极轻，仅 Hero 用）**：
- `heroGradientRise`：linear-gradient(180deg, rgba(229,70,70,0.05) 0%, rgba(255,255,255,0) 60%)
- `heroGradientFall`：linear-gradient(180deg, rgba(38,161,110,0.05) 0%, rgba(255,255,255,0) 60%)

### 4.2 字体 Token

- **数字**：`font-family: "SF Pro Display", "PingFang SC"` + `font-variant-numeric: tabular-nums`
- **正文**：`font-family: "PingFang SC", "SF Pro Text"`
- **价格字号**：40-44px（Hero），17-19px（次要）
- **间距**：8 的倍数（4/8/12/16/24/32/48）

### 4.3 动效曲线

| 场景 | 曲线 | 时长 |
|---|---|---|
| 颜色变化（涨跌切换） | ease-out | 200ms |
| Tab 切换 | `cubic-bezier(0.34, 1.56, 0.64, 1)` (spring) | 280ms |
| 卡片入场 | `cubic-bezier(0.16, 1, 0.3, 1)` (ease-out-expo) | 280ms |
| Hero 数字翻牌 | spring | 320ms |
| 实时点脉冲 | linear 循环 | 1200ms |
| 加自选按钮 | spring + scale(0.95→1.05→1) | 280ms |
| 底栏滚动压缩 | `cubic-bezier(0.4, 0, 0.2, 1)` | 200ms |

> **动效预算**：单页同时进行 ≤ 3 个动效；列表 staggered ≤ 6 项；总动画时长 ≤ 600ms 滚动区间

### 4.4 物理规则

- **缩放范围**：按下 0.95x、回弹 1.05x、归位 1.00x
- **位移范围**：translateY ≤ 12px
- **旋转范围**：≤ 8°（归因 chevron、刷新按钮除外）
- **透明度**：hover 状态最高 0.9，绝不到 1（避免"实心"）

## 5. 微交互签名（4 个"高识别度"动效）

> 品牌识别度的关键不是 logo，而是动效语言。下面 4 个动效全 App 复用，让用户一看就知道是 StockChat。

### 5.1 数字翻牌器（Ticker Flip）
- 触发：行情更新
- 效果：旧数字向下 translateY(0 → 100%) + opacity(1 → 0)，新数字从 translateY(-100% → 0) + opacity(0 → 1)
- 时长：320ms，spring 曲线
- 仅用于：当前价、涨幅

### 5.2 实时点脉冲
- 触发：常驻（"实时"徽标）
- 效果：核心圆 1.0 → 1.2 → 1.0 缩放 + 外圈圆环透明度 0.6 → 0 + 缩放 1.0 → 1.6
- 时长：1200ms，linear，循环

### 5.3 加自选成功反馈
- 触发：点击"加自选"
- 效果：
  1. 按钮 scale 0.95 → 1.05 → 1.00（弹性）
  2. 文字"加自选" → "已自选 ✓" 280ms 文字淡入淡出
  3. ✓ 勾选符号从左侧滑入（200ms）
  4. 整个按钮极轻 6px 光晕淡入（rise 色 12%α，400ms）

### 5.4 Section sticky 滑动指示条
- 触发：滚动跨越 section
- 效果：当前 section 标题旁的 2px 进度条从 0 滑到 100%（与 section 滚动进度同步）
- 时长：实时，无固定时长

## 6. 无障碍与可读性

| 项 | 规则 |
|---|---|
| 文字对比度 | 正文 ≥ 4.5:1，大字 ≥ 3:1（WCAG 2.2 AA） |
| 涨跌色 | 永远同时配 `+`/`-` 符号或"涨/跌"文字（**不**仅靠颜色） |
| 数字 | 等宽对齐避免"视觉跳变" |
| 焦点环 | 玻璃按钮点击后 1.5px `brand 50%α` 焦点环 200ms 淡入 |
| 触达区 | 底部 3 段按钮每段 ≥ 56×44px（拇指区） |
| 字号 | 主级 ≥ 28px，次级 ≥ 15px，三级 ≥ 12px（移动端最小） |
| 动效 | 全局支持 `prefers-reduced-motion: reduce`，开启时所有 spring → ease-out，时长减半 |

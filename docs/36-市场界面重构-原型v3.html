评审体验脚本（2 分钟）
1看 Hero 定性与温度计轨迹——「现在多热」一眼可答
2顶部新闻弹幕带：点击任意一条看追问路径；回放时只显示当时的新闻
3拖动叙事轴任意位置：整页回放，水印亮起、全页降饱和
4点时刻卡「13:32 二次探底」——520ms 跳帧
5切换数据切片（吸顶条）——同屏只有一张数据卡，全部随帧同步
6点任一指数（主位或 chip）——下钻大盘详情页，与市场页同帧
7打开「减少动态效果」再拖一次——动效降级、回放保留
与 v2.0（doc 20/22 原型）的结构差异
· 九区块报表流 → 纪录片三层结构：叙事层 / 数据切片层 / 口径层
· 量能、宽度、情绪、梯队、板块、资金六张纵向卡 → 4 选 1 切片容器（吸顶 segmented），同屏卡片 7 → 2
· 叙事轴 = 全页唯一主视觉 + scrub 手势（②时间机器）；竞速场⑤、温度计⑥内置于切片与 Hero
· 动效增补 N1–N7（scrub 帧同步 / 跳帧补间 / 水印 / 超车闪动 / draw-on / 切片交叉淡入 / 温度计展开），叠加在 doc 22 的 26 条之上
· 二轮增补：J1 新闻弹幕带（3 泳道匀速横滚、随帧过滤、点击追问）+ J2 指数下钻（点指数进大盘详情页，回放同帧）

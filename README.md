# 股问 StockChat

> **做股民的解释器，不做荐股机。**

一个以 AI 对话为统一入口的中文股票解释助手。用户用自然语言提问，AI 以「Markdown 文本 + 结构化卡片」混排作答，卡片可直接下钻到股票详情，长按文本里的股票名就能在顶栏看行情——**聊着天就把盘看了**。

技术底座：腾讯 Kuikly（Kotlin Multiplatform）+ OpenAI 兼容大模型（DeepSeek 等）+ 腾讯 / 东方财富公开行情接口。

产品只做三件事：**归因解释**（为什么涨/跌）、**术语翻译**（说人话）、**信源透明**（结论可溯源）。不推荐、不预测、不给目标价。

## 一、项目亮点

### 1. 意图与数据分离 —— 让 AI 幻觉污染不了任何一个行情数字

这是整个项目最重要的架构决策。LLM 的知识截止在训练数据日期，它**不可能知道今天的行情**；如果让模型直接输出价格、涨跌幅，必然是编造。

所以协议规定：

| 内容 | 生产者 | 通道 |
|---|---|---|
| 归因分析、解读文本、术语解释（定性） | LLM | Markdown 文本流 |
| 卡片意图（类型 + 标的 + 定性字段） | LLM | ` ```card:xxx ` 围栏块 |
| 卡片数字（价格/涨跌幅/OHLC/K 线序列） | 端侧 Provider（真实接口） | 渲染时按 symbol 拉取填充 |

LLM 只出意图，端侧填真实数据——这与 function calling 同构，换来的是：行情数字 100% 真实、模型输出 token 减半、卡片协议与数据源彻底解耦。

### 2. 协议驱动的通用卡片体系 —— 新增一种卡片是「加两个文件」，不是「改一处核心」

卡片类型是 **AI 输出协议的一部分**，而不是 UI 层的硬编码：AI 在回答里写 ` ```card:stock-quote ` + JSON 意图，客户端 `CardRegistry` 按类型分发渲染器，未注册类型自动走降级卡（协议天然向前兼容）。

已落地 **14 类卡片**，同一套渲染器按 **FULL / COMPACT / MINI 三级密度** 在聊天流、详情页、顶栏行情条三处复用。

### 3. 三流合一交互模型 —— 文本流 × 卡片流 × 联动层

- **文本流**：对话叙事，其中的股票名/代码/术语自动识别为可点击实体
- **卡片流**：结构化证据，折叠态只给一句话结论，点击才展开图表与全量指标（渐进式披露）
- **联动层**：长按实体，顶栏灵动岛浮现迷你行情，松手即收，**不打断对话心流**

三流都从同一句话的语义里长出来，而不是模板化推送。

### 4. 聊看一体闭环

`提问 → 混排回答 → 点卡片/实体 → 详情页 → 回到对话（恢复滚动位置）`，全程不跳出对话上下文。详情页首屏是「行情头 + AI 解读」，把传统行情软件的「数据优先」反过来，强化解释器定位。

### 5. 三级降级链 —— 演示与真机都不会因为网络挂掉

**真实接口 → 本地缓存 → 确定性离线数据**，并在界面上诚实标注当前数据模式（在线真实 / 缓存 / 离线演示），数据信源与数据时间在结论旁显式展示。宁可承认降级，也不拿 Mock 冒充在线结果。

### 6. 自绘图表引擎，数据与渲染彻底分离

分时 / 日 K / 周 K / 月 K + MA5/10/20 全部用 Kuikly Canvas 在 `commonMain` 纯 Kotlin 自绘：坐标计算、刻度、数据窗口全在纯函数层，可跨端复用、可单测；渲染层只做「几何 → Canvas 指令」的映射。

### 7. 四端同源 + 平台隔离层 —— 某端的修复不会外溢到其他端

一套 `commonMain` 代码同时服务 **Android / iOS / 鸿蒙 / H5**。为了让 iOS 侧的激进修复不影响已稳定的 Android，项目立了一条硬规则：用 `expect/actual` 的 `PlatformPolicy` 做单一开关，**iOS 验证期的行情/图表/线程修复默认只对 iosMain 生效**，Android/鸿蒙/H5 保持全 false，调用点零改动。新增 commonMain 修复时必须先回答「其他端要不要」。

### 8. 合规与反游戏化设计

交互创新的目的是**降低理解成本，而不是刺激交易频率**：不做庆祝动画、不做 FOMO 榜单、不做一键下单；不输出买卖指令、目标价或收益承诺。涨跌色走语义 token（A 股红涨绿跌，颜色不是唯一信号，涨跌同时带 ▲▼ 箭头做色盲友好）。

## 二、做了哪些功能

### 对话与问答（ChatPage）

- 真 SSE 流式输出 + 打字机增量渲染，支持**停止生成**与重试
- Markdown 与卡片混排渲染；流式中卡片 JSON 未闭合显示骨架卡，闭合瞬间替换
- 多轮上下文（带裁剪）+ 会话本地持久化 + 侧边栏会话历史
- 回答前显式复述问题理解，可一键纠正
- 追问建议 chips（仅在最新成功回复中有效，避免历史建议乱触发）
- 应用内 API 配置页 + 连接测试，**Key 不进源码、不进 APK**、不写 URL 参数

### 卡片体系（14 类）

- 行情侧 7 类：行情快照、走势图、AI 解读、归因链、术语、资讯、双标的对比
- 数据侧 7 类：资金流、财报、股东户数、龙虎榜、分红事项、公告披露、产品概念
- 全部支持三密度复用、降级渲染、信源与数据时间标注

### 输入增强

- `@` 唤起标的联想、`/` 唤起斜杠指令（复盘等），指令面板带参数填写
- 多行自适应输入框，明暗主题与字号档下的颜色/光标行为经过专门修复
- **语音输入**：按住说话、松开发送、上滑取消（对标微信范式）

### 实体交互

- Trie 最长匹配 + 会话上下文消歧（同名词优先取对话中出现过的标的）
- 单击实体进详情，长按实体在顶栏灵动岛预览行情，可直接切自选或进详情
- 实体可拖拽进输入框，自动组装提问上下文

### 股票详情页（StockDetailPage）

- 分时 / 日 K / 周 K / 月 K 切换 + MA5/10/20 + 均价线与昨收基准线，图表支持十字光标与时间刷
- 指标区、AI 解读与涨跌归因工作台、公司介绍与数据、公告与研报
- 资金流、财报、股东户数、龙虎榜、分红事项、公告正文摘要、券商研报

### 市场页与热点（MarketPage / HotspotPage）

- 市场总览四视角：市场宽度、量能资金、板块竞速、连板梯队（8 时段态）
- 板块热点、涨停池（连板 / 封单 / 开板次数）
- AI 复盘卡：复盘锚点由端侧事实槽位生成，模型只许引用时间点，坐标由端侧映射
- 财报日历、历史回放

### 自选 · 风险 · 知识（三模块闭环）

| 模块 | 核心能力 |
|---|---|
| **自选股** WatchlistPage | 关注理由记录与「当初理由对照」、分组状态色带、异动标记、左滑操作行 + 限时撤销、拖拽排序、对话置顶、久未查看提示 |
| **风险地图** RiskMapPage | 六维暴露解释器（行业集中度 / 相关性矩阵 / 波动对比 / 事件时间线 / 情绪暴露）、每周暴露快照、跑输大盘归因 |
| **知识库** GlossaryPage | 80 条术语（含拼音与别名检索）、依赖路径知识地图、「下一步该懂什么」推荐、对话中自动记录「遇到过」 |

三者构成闭环：**自选（我在看什么）→ 风险地图（押了哪些共同变量）→ 知识库（还缺什么）→ 回自选**。

### 其他

- 全局搜索：代码 / 名称 / 拼音 / 术语一网打尽
- 异动预警中心：前台轮询 + 归因说明，风险地图与自选作为生产端写入收件箱
- 分享长图 + 文案一键复制
- 明暗主题 + 字号档 + 涨跌语义色；卡片画廊页（开发期组件独立预览）
- 术语「遇到即记」埋点，术语解释支持一句话 / 一段话 / 例子 / 数据三档深度

## 三、最终实现了什么

**一套代码、四端可构建、全链路闭环跑通的产品**：

- **交互闭环**：提问 → 流式混排回答 → 卡片/实体下钻 → 详情页 → 回到对话，完整可演示
- **数据闭环**：腾讯行情（快照 / 分时 / 日周月 K）+ 东方财富（资金流 / 板块涨停池 / 财报 / 股东户数 / 龙虎榜 / 分红 / 公告 / 研报）双源接入，统一走真实 → 缓存 → 离线三级降级
- **工程规模**：`commonMain` 约 185 个 Kotlin 文件、4.8 万行；13 个业务页面；14 类卡片
- **质量基线**：`./gradlew :shared:testDebugUnitTest` = **298 tests / 0 failures / 0 errors**，覆盖协议解析、行情字段解析、图表算法、实体识别、状态机与架构边界
- **架构门禁**：`scripts/check_architecture.sh` 自动扫描包依赖方向，命中未登记的反向依赖即构建失败；Page 的 Timer / Provider / observable 计数只许降不许升，`page/components/` 禁止新增文件
- **文档沉淀**：`docs/` 下 48 篇编号文档 + 22 篇可交互原型 HTML，覆盖调研、PRD、交互规范、技术方案、卡片规范与逐波重构施工书

### 已知缺口（诚实标注）

- iOS 侧已跑通页面级模拟器冒烟验证，但**宿主桥的上传与语音模块尚未实现**（页侧表现为「点了没反应」），且 `Info.plist` 还缺相册/相机用途描述
- 鸿蒙侧仅完成构建链路（需 DevEco SDK 环境），未做真机走查
- H5 产物用于浏览器演示分发；生产环境必须由自有后端代理大模型请求，浏览器前端无法安全隐藏密钥
- 推送、云同步、词库热更新等 P2 项未排期

## 四、跑起来

```bash
# 单元测试（最常用的回归入口）
./gradlew :shared:testDebugUnitTest

# 架构门禁
bash scripts/check_architecture.sh

# Android Debug APK
./gradlew :androidApp:assembleDebug
# 产物：androidApp/build/outputs/apk/debug/androidApp-debug.apk

# H5 产物（需配合 h5App 静态服务；开发期默认从 127.0.0.1:8083 加载共享业务脚本）
./gradlew :shared:jsBrowserDevelopmentExecutableDistribution

# 鸿蒙（ohos 任务由独立 settings 文件注册，且需要 DevEco SDK 环境变量）
./gradlew -c settings.ohos.gradle.kts :shared:linkDebugSharedOhosArm64
```

iOS 为两段式构建：先 `:shared:linkPodDebugFrameworkIosX64`，再 `cd iosApp && pod install`，然后用 `xcodebuild -target iosApp` 出模拟器产物。

### 在线服务配置

腾讯行情接口不需要密钥。大模型配置**不写入源码 / `local.properties` / URL 参数 / `BuildConfig`**：启动 App 后从聊天页右上角进入「API 设置」，填 API 地址、模型名与 Key，可先测试连接再保存。配置只保存在当前设备。

### 工程组织

- `shared/src/commonMain` — 跨端业务与 UI（页面、卡片、协议、数据、图表、实体富文本）
- `shared/src/commonTest` — 跨端单测；`shared/src/{android,ios,js,ohosArm64}Main` — 平台适配层
- `androidApp` / `iosApp` / `ohosApp` / `h5App` — 四端宿主壳，不含业务逻辑
- `scripts/` — 架构门禁脚本与白名单/基线快照；`docs/` — 文档套件与原型

## 五、产品边界

所有 AI 内容与归因结果都属于解释性信息，**不能替代公告原文、持牌机构意见或个人投资决策**。界面不输出「建议买入」「目标价」或任何收益承诺。行情来自免费公开接口，可能存在延迟，界面上会标注数据来源与数据时间。
